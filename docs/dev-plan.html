02测试策略总则

  1. 单元测试：后端 pytest 覆盖 services / core 核心逻辑（环境解析、探活判定、采集换算、告警状态机、JWT/密码、Flow 表达式沙箱、通知路由）；前端 Vitest 覆盖 stores、搜索过滤、布局序列化、工具函数。
  2. 接口测试：FastAPI TestClient + httpx AsyncClient，连接临时 SQLite（内存库），覆盖 API 契约与权限（401/403）。
  3. 业务功能测试：以《功能详述》的功能点编号（如 M04-10）为验收单元，每阶段列手工测试清单逐条勾验；关键链路在 M1 末补 Playwright 自动化。
  4. 覆盖率门禁：后端核心 services ≥ 80%、全局 ≥ 70%；不达标不得关闭阶段。
  5. 状态更新约定：完成一个步骤 → 状态 ⬜→✅ 并在 logs/ 记一笔；阶段内步骤全 ✅ 且两道测试关卡通过 → 阶段 ✅；被卡住 → ⛔ 并注明原因。
