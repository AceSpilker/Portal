## 需求原意

进入 M3 的第一个阶段：**P19 · Flow 画布编排**（3 步）——19.1 画布编辑器（Vue Flow 拖拽节点/连线/分支并行）、19.2 进阶节点（SSH 命令/Docker 操作/AI 调用/延时变量）、19.3 模板与分享（内置模板 + JSON 导入导出）。定位：把 M2 的"表单式编排"升级为轻量版 n8n 画布。

## 已完成

### 后端
- **画布数据模型**：flows 表新增 `graph` TEXT(JSON) 列（{nodes,edges}，NULL=表单模式；init_db 轻量迁移）；
- **互转**（P19.1）：`linear_to_graph`（trigger 起头串连，条件出边标 true）/ `graph_to_linear`（主路径投影：条件取 true、fan-out 取首边）——画布保存时自动把线性投影写回 actions，表单视图兼容；
- **图校验**：validate_graph——节点类型白名单（trigger/condition/http/notify/ssh/docker/ai/delay/variable）、≤60 节点、Kahn 拓扑 DAG 无环检查、边引用完整；
- **图执行引擎** `execute_graph_flow` + `_walk_branch`：从无入边节点遍历；**条件节点独占路由**（真走 true 边/假走 false 边，无边则支线成功终止）；**fan-out 并行**（节点多出边 asyncio.gather，各支线独立变量副本 + 独立 DB 会话——SQLite 异步会话不可并发共享）；节点级重试（flow.retry/retry_interval），失败传播 failed + flow_failed 告警；dry-run 不写 last_run_at；
- **进阶节点**（P19.2）：`_run_ssh_action`（asyncssh 密码认证，30s 超时，输出截 2KB，exit≠0 视为失败）、`_run_docker_action`（复用 docker_svc.container_op，start/stop/restart）、`_run_ai_action`（活动 Provider 非流式 chat/completions，上游 prev 注入提示词，结果传下游）、delay（≤300s，dry-run 跳过）、variable（写 vars 供后续插值）；
- **模板与分享**（P19.3）：三个内置模板（离线自动重启/每日下载摘要/定时巡检+延时复检，均含画布图）；GET /flows/templates、POST /flows/from-template（默认停用）、GET /flows/{id}/export（剔除 token/id）、POST /flows/import（校验图→graph 存储旧格式自动升级画布，重生成 webhook token，默认停用）。

## 过程中发现并修复

1. **条件路由漏独占**：初版条件为真时既走主循环又触发 fan-out 双分支（false 支线误执行）——改为条件结果独占选择 true/false 边；
2. **并行分支共享 AsyncSession**：SQLite 异步会话不可并发使用（通知表 id 冲突）——fan-out 各支线改用独立 SessionLocal；
3. **/flows/templates 被 /flows/{flow_id} 吞**：路由注册顺序——模板路由前移；
4. **linear_to_graph 漏条件 true 边标注**：边基于"前一节点是否条件"补 source_handle；
5. **BizError str 为空**：节点错误日志不可读——错误提取兜底 `getattr(exc,'message')` + 类名；
6. 画布 watch 缺 immediate：对话框挂载时 visible 已为 true 导致图未初始化。
