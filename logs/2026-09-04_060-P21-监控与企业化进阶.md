# 060 · P21 · 监控与企业化进阶（数据报表/Web 终端/多机纳管/Docker 增强）

## 需求原意

M3 第三阶段：**P21 · 监控与企业化进阶**（4 步）——21.1 数据与报表（监控 CSV 导出/性能报表/监控大屏）、21.2 Web SSH 终端（xterm.js 直连 NAS Shell、开关与审计）、21.3 多机纳管（轻量 Agent 上报 + SNMP 采集）、21.4 Docker 增强（批量操作/事件通知/镜像管理/更新检测）。

## 已完成

### 后端
- **21.1 数据与报表**：`GET /api/monitor/export?metric=&range=`（复用历史聚合口径 → CSV）；`GET /api/monitor/report?days=`（按天 min/avg/max 聚合，mem 由 used/total 换算）；大屏=前端监控页「大屏模式」（见前端）；
- **21.2 Web SSH 终端**：`WS /ws/ssh-terminal?token=&cred=`——JWT 鉴权（API Token 不可用）、开关 `security.webssh_enabled`（默认关）、复用 P20 凭据库 asyncssh 连接 + create_process（xterm）、连接/断开写审计；
- **21.3 多机纳管**：`agent_nodes` 表（hostname UNIQUE + token SHA-256 + 最新快照 cpu/mem/disk/uptime/version）；`POST /monitor/agents/report`（token 恒时比较；未启用 403、错 token 401）；`GET /monitor/agents`（180s 在线判定）；`POST /monitor/agents` 注册（token 明文一次，写 monitor.agent_token）；`GET /monitor/agents/script` 生成 psutil+httpx 轻量脚本；monitor_samples 补 `node` 列；
- **SNMP** `services/snmp.py`：纯标准库 BER 编解码 SNMP v2c GET（无外部依赖）；`POST /monitor/snmp/test` UDP 单请求 2s 超时；编解码对称性单测验证；
- **21.4 Docker 增强**：`POST /docker/batch`（逐容器执行、单失败不影响）；`GET /docker/images`、`DELETE /docker/images/{id}`；`GET /docker/updates`（latest 镜像构建超 30 天提示——registry digest 对比为预留）；`events_since` 轮询 /events（die/start/destroy）供事件通知。

### 前端
- 监控页工具栏：导出 CSV（BOM）/性能报表对话框/多机纳管对话框（注册+清单+在线 tag）/大屏模式（全屏 class + Fullscreen API，Esc 退出）；
- DockerView：多选列 + 批量重启/停止 + 镜像管理对话框（删除）+ 更新检测对话框；
- ToolsView：Web SSH 终端卡片（凭据选择 + xterm 对话框，WS 直连）；
- settings 白名单补 security.webssh_enabled；i18n zh+en。

## 过程中发现并修复

1. **p13 测试遗留 httpx 全局污染**：`httpx.Client.__init__ = httpx.AsyncClient.__init__`（"防误改"注释行）永久破坏 httpx 类层级——p20 新建 TestClient 即触发 super TypeError；删除该行并回补 p13 意图（MockTransport 拦截）；

3. Docker batch 测试的 fake `_client` 返回裸协程不支持 async with → 改 FakeCM 上下文类；
4. MonitorSample.mem JSON 无 pct 字段——报表用 used/total 换算。
