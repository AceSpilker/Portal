## 完成情况

### 1. 错误提示文案修复

- **根因**：传输加密上线后，**错误响应也是密文信封**（如登录失败返回 HTTP 401 + 加密的 `{"code":1001,"message":"用户名或密码错误"}`）。axios 错误拦截器此前**没有先解密**就直接取 `message`，取不到 → 退回显示生硬的 "Request failed with status code 401"；
- **修复**：错误拦截器先经 `decryptBody` 解密信封，再取 `code/message`（frontend/src/api/request.ts）；
- 修复后：登录失败显示"**用户名或密码错误**"，弱密码注册显示具体规则等，全部为友好中文文案。

### 2. SQLite 重置

- 停止后端 → 删除 `backend/data/portal.db` → 重启；
- 当前系统为**未初始化**状态（`initialized: false`），浏览器刷新 http://localhost:5173 会进入**初始化向导**，重新创建你自己的管理员账号密码即可。
