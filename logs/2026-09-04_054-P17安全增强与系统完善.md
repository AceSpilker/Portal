## 已完成

### 后端（184 例全绿，新增 7 例）
- **TOTP** `services/totp.py`：RFC 6238 标准库实现（无新依赖），±1 窗口时钟容差、恒时比较；恢复码 8 条 SHA-256 存储单次有效；登录链路接入（专用错误码 **1007**=需验证码），恢复码命中即销毁；
- **会话管理** `user_sessions` 表：登录登记（refresh jti/UA/IP/过期），`GET/DELETE /api/auth/sessions`；refresh 端点校验吊销（被踢设备 refresh 401）；
- **API Token** `api_tokens` 表：`plt_` 前缀、SHA-256 存储、明文仅创建返回一次；`core/deps.py` 双通道鉴权（JWT 与 `Bearer plt_…`），**ro scope 非安全方法 403**；`GET/POST/DELETE /api/tokens`；
- **审计**：登录成功/失败写 audit_logs；`GET /api/audit-logs`（动作/用户/时间筛选分页）+ `/export` CSV；
- **备份** `services/backup.py`：collect_all/restore_all 全量业务数据（应用/入口/分组/环境/Flow/设置/渠道/WoL）；`/api/backup/export·import`、`/api/backup/factory-reset`（密码二次确认，先落盘备份）；自动备份任务（每日，data/backups 保留 N 份）；
- **健康自检完整版** `/api/system/health-report/full`：+外网连通（gitee 3s）/最近备份时间/MySQL·Redis·AI 预留位；
- **在线更新**：`update/check`（Gitee Releases API，版本号比较，新版本站内通知 dedup per version）、`update/apply`（源码部署：备份→git fetch→checkout tag→pip 依赖，失败回滚原 ref；--reload 环境文件变更自动重载）、`update/status`；6h 定时检查任务（auto_check 可关）；
- **注册** `GET /api/auth/config`（公开）+ `POST /api/auth/register`（开关默认关，密码长度策略 security.password_min_length）。

## 过程中发现并修复

1. **AsyncSession.merge 未 await**（restore_all/factory_reset）：设置合并静默丢失，导致全量跑 settings 用例 KeyError——协程遗漏只在后续读端暴露；
2. **write_audit 是 async**：登录审计忘 await（RuntimeWarning 暴露）；
3. Vue 模板不允许 `<style>` 标签（side-effect tag 编译错误）——自定义 CSS 改为手动 DOM 注入；
4. workbox 默认 2MB 预缓存上限 < 主包体积导致 build 失败，调至 4MB；
5. 开发库 admin 密码与日志 043 记录不符（此前会话又改过），已按既有做法重置为 **Portal123** 并在此明示；
6. P17 测试的恢复出厂在共享测试库上清空了设置——已通过 import round-trip 恢复，且确认对后续模块无污染（全量 184 绿）。
