# 102 · 日历格待办显示优化 + 整格点击修复

## 需求原意

用户对效率画面日历格内显示的四点反馈：

1. 待办缩略**字号调大**一点；
2. 不要只显示前 5 个字符，**正常显示内容，显示不下再出 …**；
3. **节日名称显示在日期右侧**，不显示在待办事项下面；
4. bug：点击日期块**只有特定位置才会弹事件窗**；
5. 待办**完成后**，日期块内的显示要有**对应的完成效果**。

## 完成情况（纯前端，`SchedulePanel.vue`）

### 1. 待办缩略：完整内容 + 自适应省略 + 字号调大

- 删除 `shortTodo`（前 5 字符截断），格内直接渲染完整标题；
- 依靠 `overflow:hidden + text-overflow:ellipsis + white-space:nowrap`
  自适应：放不下自然出 …（长标题能显示多少取决于格子宽度，不再固定 5 字）；
- 字号 10px → **11.5px**。

### 2. 节日移到日期右侧

- 日期数字与节日名（如"25 中秋节"）合并进 `.cell-head`
  （flex baseline 横排，数字不收缩、节日超宽省略），
  节日不再作为独立行出现在待办下方；字号 10.5px → 11px。

### 3. 整格任意位置可点击（bug 修复）

- 根因：`@click` 在格内 `.cell` div 上，而 `.el-calendar-day` 自带 8px padding、
  `.cell` 只有 `min-height:52px`——格子被 100 布局拉高后，内容区以下的
  大片区域不属于 `.cell`，点了没反应；
- 修复：`.el-calendar-day` padding 归零，`.cell` 自带 `padding:8px` 且
  `min-height:max(52px, 100%)`——宽布局下 `.cell` 撑满整格（含原 padding 区），
  窄布局（高度不定）退化为内容高度并保底 52px，`max()` 内百分比无法解析时按 0 取 52px。

### 4. 完成态显示效果

- `todosOn` 已有"未完成排前、完成排后"排序（099）；
- 格内缩略按 `td.done` 加 `.done` 类：**划线 + 置灰 + 中性浅底**，
  与未完成（主题色浅底）一眼区分。
