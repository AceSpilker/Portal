# 103 · 日历选中日期主题融合色高亮

## 需求原意

用户反馈：效率画面日历上"选中的那个日期"需要用**另外的一种背景融合色**显示——
项目有主题色（--p-primary），希望基于主题色调一个融合色标注当前选中日期；
因为右侧"当日事件"卡展示的正是这个选中日期，日历上应能一眼对应。

## 背景回溯

- 099 按当时需求移除了 EP 默认的点选背景（`td.is-selected` 透明化），
  仅保留"今天"高亮——本轮在 099 基础上把"选中"语义以自定义融合色加回，
  与"今天"的中性高亮形成两种视觉状态。

## 完成情况（纯前端，`SchedulePanel.vue`）

- 模板：`.cell` 绑定 `:class="{ selected: data.isSelected }"`
  （EP 日历 date-cell 插槽自带 `isSelected`，跟随 el-calendar 的 modelValue）；
- 样式：
  - 背景 `color-mix(in srgb, var(--p-primary) 13%, transparent)`——主题色
    与透明的融合色，明暗主题自适应；
  - `border-radius: 10px` 圆角块 + `inset 0 0 0 1px` 30% 主题色描边一圈，
    "选中块"语义更明确；
- "今天"高亮不变（EP 中性 `--el-calendar-selected-bg-color` 铺在 td 上），
  选中 16 日与今天 11 日同屏两种底色、互不干扰；选中今天时两者叠加、
  融合色在上层。

## 测试结果

- 前端：vitest **57/57** ✅、eslint ✅、vue-tsc + build ✅；
- 后端：全量 **257 passed / 2 skipped** ✅（未动后端，回归确认）；
- **浏览器实测**（临时实例 8010/5180）：点击 16 日 → 该格显示主题融合色
  圆角高亮块，右侧当日事件卡标题同步为 2026-09-16；今天(11)保持原中性
  高亮，二者区分明显；
- 无接口/表/枚举变更，契约文档无需同步。
