# 091 · 知识库模块：目录源 / git 同步 / 多格式在线阅读编辑

## 需求原意

用户新增一个"知识库"目录功能：
1. 内容来源两种——**服务器映射文件目录**（挂载目录原样读取，不用拷贝）和 **git 地址**
   （下载内容到 docker 容器存放目录，支持同步操作）；
2. 支持在线阅读与编辑，文件类型要广：md、html、office 全套、代码文件、视频、图片等。

## 设计

- **数据源模型** `knowledge_sources`：kind=local（容器内可见的映射目录，文件原样读取零拷贝）/
  git（克隆到 `data/knowledge/{id}/` 数据卷持久化）；git 支持 branch 与私库凭据
  （username + password，Fernet 加密存储，与 MySQL 同密码盒，永不通传）；
- **git 同步引擎**：dulwich 纯 Python 实现——容器内**免装 git**；同步策略 pull（fast-forward）
  失败自动删除克隆重建；同步结果回写 last_sync_at/last_commit/last_status/last_error；
- **类型分发**（按扩展名，`knowledge_fs.file_kind`）：markdown/代码/文本（可编辑）、html
  （沙箱 iframe）、图片、视频、音频、pdf（原文件流，starlette FileResponse 自带 Range
  视频拖动）、office（docx/xlsx/pptx 服务端转 HTML）、老格式 binary（仅下载）；
- **Office 预览**（knowledge_office.py）：docx→mammoth、xlsx→openpyxl 表格、
  pptx→python-pptx 大纲，均服务端转换前端直出（无 office 套件依赖）；
- **安全**：`safe_join` resolve 前缀校验杜绝路径穿越；hidden/依赖目录（.git/node_modules 等）
  不入树；local 源可写、git 源只读（改动应回仓库再同步）；读取所有登录用户，管理管理员。

## 完成情况

### 后端

- 模型 `knowledge_sources`（轻量迁移自动建表）+ 注册 models/__init__；
- 服务：knowledge_fs（safe_join/tree/file_kind）、knowledge_git（dulwich clone/pull/重建，
  certifi CA 束修复无系统根证书环境的 SSL 校验）、knowledge_office（三格式转换）；
- API（api/v1/knowledge.py）：sources CRUD + sync、tree、read、raw、file 写回；错误文案
  i18n 双语；路由注册 tags=["knowledge"]；
- requirements.txt 增 dulwich/mammoth/openpyxl/python-pptx。

### 前端

- 新增 `/knowledge` 路由与侧栏「知识库」入口（Reading 图标）；
- `KnowledgeView.vue`：左侧数据源列表（kind 标签/同步/编辑/删除，管理员可见管理钮）+
  el-tree 懒加载目录树；右侧查看器按 kind 分发——markdown 用 marked+DOMPurify 渲染、
  文本/代码编辑器（textarea）保存回写、html/pdf iframe、img/video/audio、office HTML 直出、
  binary 下载提示；
- 数据源管理弹窗（类型切换/路径/URL/分支/凭据/启用）；`api/knowledge.ts`；
- npm 增 marked、dompurify。

## 关键决策

1. git 用 dulwich 而非系统 git：容器镜像免增 apt 层，python 依赖随 pip 装机即用；
2. pull 失败自动重建：文档仓库追求"最终与远端一致"，不做合并/变基交互；
3. office 走服务端转换而非前端 JS 解析：前端零重依赖（仅 md 渲染加 marked/dompurify），
   转换口径服务端可控；
4. 编辑范围收敛在文本类 + local 源：office 在线编辑需完整套件，明确不做并给出下载提示。

## 遗留

- git 仅支持 https（ssh 密钥方案未做）；同步为手动/建源触发，未接定时（可后续加 cron）；
- pptx 仅文本大纲预览（无版式/图片还原）；老格式 .doc/.xls/.ppt 仅下载；
- NAS 使用 local 源需先在 compose 追加映射（如 `/volume1/docs:/knowledge/docs:ro`）。
