# 工作日志 · 2026-09-01 · 014：画面自适应专项优化（flex 应用式布局）

> 记录人：ZCode ｜ 性质：响应式布局专项优化与多尺寸实测

---

## 需求（用户原意）

整体画面现在需要上下滚动，自适应效果不太好。不要使用固定像素，最好使用 flex 布局，所有内容基本都要能够自适应。

## 排查与修复

### 1. 布局架构：改为"应用式弹性布局"

- 仪表盘外壳改为 `height: 100dvh + overflow: hidden`——**页面本身零滚动**；
- 纵向 flex 分层：顶栏/欢迎横幅/页脚 `flex-shrink: 0`，卡片网格区 `flex: 1 + overflow-y: auto`——内容超出时**只有卡片区内部滚动**；
- 侧边栏由 sticky+固定高改为 flex 拉伸（自动占满一屏），宽度 `clamp(200px, 16vw, 216px)`；
- 间距全面改用 `clamp()` 流式值，消除硬编码像素。

### 2. 平板断点（768~1079）：图标栏

新增平板专属形态：侧边栏收窄为 68px **图标栏**（隐藏文字/标签/用户名，图标居中），内容区获得最大宽度。

### 3. 响应式切换改为纯 CSS 媒体查询（重要修复）

排查发现 JS 断点状态（useMediaQuery ref）在视口切换后偶发不更新，导致侧栏/底部 Tab 显隐错乱。已将布局显隐**全部改由 CSS 媒体查询驱动**（浏览器原生、永不失灵），JS 断点仅保留给行为逻辑使用。

### 4. 其他修复

- 登录页：`min-height: 100dvh` + `clamp()` 间距 + 移动端输入框/按钮增高（拇指友好）；
- 全局补 `box-sizing: border-box`——修复 min-height+padding 撑出 48px 页面滚动的经典问题（登录页此前所有尺寸都有页面滚动的根因）；
- 网格列数：`repeat(auto-fill, minmax(min(230px, 100%), 1fr))`（min 内嵌 100% 防小屏溢出）。
