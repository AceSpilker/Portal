# 100 · 效率/端口/Flow 三画面内容区撑满右侧高度

## 需求原意

用户反馈：效率画面、端口画面、Flow 画面这三个画面，右侧的内容显示区域
没有撑满右侧画面的高度（卡片到视口中途就结束，下方留背景空白），要求撑满。

## 现状分析

全局已有滚动规范（081）：`.page-anim > *` 使页面根 `height:100% + overflow-y:auto`，
三个画面根容器高度本来就是满的——问题出在**根内的主内容卡没有纵向拉伸**，
内容按自然高度顶对齐，剩余空间露在卡片外：

- 效率：`.eff` 根已 fill，但 `.schedule` 网格 `align-items:start` 且不 grow，
  日历卡与右侧两卡到内容高度即止；
- 端口：`.ports-page` 根只有 `flex-direction:column`，`.tabs-card`（页签卡）自然高度；
- Flow：`.flow-page` 同上，`.list-card` 自然高度。

## 完成情况（纯前端样式，无接口变更）

### 1. 效率画面（`SchedulePanel.vue`）

- `.schedule` 加 `flex:1` 并去掉 `align-items:start`（恢复 stretch），
  日历列与侧栏列整体撑满；
- 日历卡 `.cal-wrap` 改 flex column，深度覆盖 el-calendar：
  根/`__body` 逐级 `flex:1`，`.el-calendar-table { height:100% }`，
  `.el-calendar-day { height:100% }`——**日历格子随视口高度均分拉伸**；
- 右侧 `.side` 两张卡（当日日程/待办）`flex:1` 均分高度，`.day-list`
  由 `max-height:320px` 改为 `flex:1 + overflow-y:auto`（列表内部滚动）。

### 2. 端口画面（`PortsView.vue`）

- `.tabs-card`（页签玻璃卡）`flex:1 + min-height:0 + flex column`；
- 深度规则：`.el-tabs__header` 不收缩，`.el-tabs__content` `flex:1`，
  `.el-tab-pane` `height:100% + flex column + overflow:auto`（各页签内部滚动）；
- 端口总览表由写死 `height="480"` 改为包一层 `.table-fill(flex:1)` +
  `height="100%"`——表格随剩余高度自适应、表头固定内部滚动。

### 3. Flow 画面（`FlowView.vue`）

- `.list-card` `flex:1 + min-height:0 + flex column`，表格加
  `class="fill-table" + height="100%"`，卡撑满、表格内部滚动（空态时
  卡片同样到视口底）。

## 调试坑记录

1. 本机 5173/5174 已被用户自己的 dev 环境与其他项目（TunnelDesk）占用，
   测试实例须 `--strictPort` 换端口——首次 5174 被占导致浏览器打开的是别家应用，
   靠 `<title>` 复核才发现；strictPort 保证失败显式化；
2. el-table `height="100%"` 确认受支持（`parseHeight` 对非纯数字字符串原样返回），
   配合确定高度的 flex 父容器即可自适应。

## 遗留

- 端口「监控项」页签表格仍为自然高度（内容超出时页签容器内部滚动），
  如需表格也拉伸可复用 `.table-fill` 模式；
- 其余画面（监控/Docker 等）未在本次范围，若有同类观感可后续同法处理。
