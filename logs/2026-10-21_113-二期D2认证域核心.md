# 113 · 二期 D2（9/12）：认证域核心——登录全家桶打通 + 浏览器真实登录

## 需求原意

用户在 5175/portal 登录页尝试登录报"服务器内部错误，请稍后重试"。根因是
排期：D0 只交付骨架，认证域（D2）未开发。本轮将 D2 核心提前完成，交付可
登录的最小闭环。

## 实现（D2.1–D2.9 完成）

1. **模型**：apps/accounts/models.py（User/UserSession/ApiToken）+ apps/core/
   models.py（Setting）——表名列名对齐一期（users/user_sessions/api_tokens/
   settings），迁移已建表。
2. **security.py / ratelimit.py / totp.py**：自一期逐行移植（JWT HS256、
   access 30min/refresh 7d/token_version/jti；限流 5 次/分；TOTP RFC6238
   标准库实现——Mimosa 对 HMAC-SHA1 的弱算法告警属规范要求误报，保留）。
3. **deps.py**：Ninja 形态双通道鉴权（Bearer 前缀可选 + plt_ API Token +
   ro 拒写 + 黑名单 + ver 校验）。
4. **端点**（apps/accounts/api.py，路径/错误码与一期一致）：
   init/config/register/login/refresh/logout/me/**user/info**/password/
   totp×3/sessions×2。ADP 增量：userName 别名、{token,refreshToken} 超集
   （旧字段全保留）、user/info 返 roles→R_ADMIN/R_USER。
5. **测试**：tests/test_auth.py 14 例（初始化/超集/别名/1005/1001/1006 限流/
   config/me 裸头+Bearer 双形态/user-info 契约/1002/refresh/登出黑名单/改密
   踢全端/TOTP 全流程 1007/会话吊销）。**全套 26 用例绿 + ruff 干净**。

## 决策（重要，均为 Django/Ninja 与一期 FastAPI 的差异）

- **ninja 1.7.1 已移除 `Depends` 与 `csrf` 构造参数**：依赖注入改为端点内
  自调用（`await get_current_user(request)`）；端点首参必须 `request`。
- **`body: dict` 不映射请求体**（按 query 解析）——TOTP enable/disable 改
  用显式 Schema（CodeRequest 等）。
- **Django async ORM（acreate/aget）经 sync_to_async 在线程池执行** →
  线程本地第二连接 → pytest-django 测试事务包裹会 sqlite 跨连接写锁：
  auth 测试用 `django_db(transaction=True)` + 用例前清表（含 sqlite_sequence
  序列重置）保证隔离与 userId 确定性。
- **dev 后端以 ENCRYPT_ENABLED=false 运行**：stock ADP 前端尚无加密层
  （F1 移植 secure.ts 后切回）；加密链路本身由 test_crypto 7 例在
  override_settings(ENCRYPT_ENABLED=True) 下全绿保障。
- USE_I18N=False（文案本地化由自研 i18n.py 承担，避免 Django 找 zh-CN
  翻译文件报错）；UserSession.expires_at 存 aware datetime（make_aware）。
