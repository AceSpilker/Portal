### 1. 在线更新策略设计（新增 17.5，M15-9 扩充）

- **版本源**：Gitee Releases（`/api/v5/repos/{owner}/{repo}/releases/latest`，tag=版本、body=更新日志；`update.repo` 可配，默认 acespilker/portal）；本地版本构建注入（health 已返回）；
- **检查**：定时 6h + 手动，semver 对比 → has_update 站内通知管理员（source=system）；
- **更新路径（按部署形态）**：
  - 源码部署：一键更新——自动备份（SQLite 全量导出）→ `git fetch --tags` checkout 新 tag → 依赖安装 → 进程重启（init_db 轻量迁移自动）→ 健康自检；失败自动 checkout 旧版本 + 恢复备份；
  - Docker 部署（NAS 主形态）：半自动——提示新版 + 展示/复制 `docker compose pull && up -d`（数据卷保留历史不丢）；挂载 docker.sock（P12）后可一键执行；
- **安全约束**：仅管理员；默认只检查提醒不静默更新（auto_check 开 / auto_apply 关）；更新期间前端遮罩轮询 /api/health；写审计日志；
- **端点**：GET /api/system/update/check · POST apply · GET status；
- **排期**：新增 **P17.5**（M2，P8 compose 定型部署形态后实施）；P17.3 中"版本更新检查"拆出。
