# 075 · 全局弹窗高度约束：正文内部滚动替代整窗滚动

## 需求原意

用户反馈：监听变更历史弹窗应该**内容垂直滚动**，而不是整个弹窗滚动；并要求整体检查所有对话框——高度不能超过窗口高度。

## 根因

`监听变更历史` 弹窗正文是 v-for 的历史卡片列表，条目多时 `.el-dialog` 高度涨到 2200px+（视口 900），超出部分靠**遮罩层整体滚动**——标题栏和内容一起滚走。全局样式表对 `.el-dialog` 无任何高度约束，全站十余处弹窗同此行为。

## 完成情况

`src/styles/index.css` 新增全局规则（一处修复覆盖全站约 15 个文件的所有弹窗）：

```css
.el-dialog {
  display: flex;
  flex-direction: column;
  max-height: calc(100vh - 48px);
  margin: 24px auto;
}
.el-dialog__header { flex-shrink: 0; }
.el-dialog__body   { flex: 1; overflow: auto; }
.el-dialog__footer { flex-shrink: 0; }
```

效果：任何弹窗高度被钉在视口内（上下各留 24px）；头部（标题/关闭）与底部（按钮）常驻；只有正文区域内部滚动。

## 测试结果

- 本地 dev（localhost:5173）实测两档视口：
  - 1600×900：监听变更历史弹窗高 852 ≤ 900，正文内部滚动（bodyScrolls=true，overflowY=auto）；
  - 1280×680：弹窗 top=24 / bottom=656，完整落在视口内，头部固定、正文滚动条可见；
- 表单类弹窗抽查（新建应用，实为右侧抽屉形态）：全高、底部按钮固定，不受影响；
- build/eslint ✅（vitest 不涉及样式）。

## 关键决策

1. **全局样式而非逐弹窗改造**：一处规则覆盖存量与未来新增弹窗；个别弹窗仍可用 `top` 属性/自定义类覆盖；
2. 排查经验：本项目 EP 版本弹窗 DOM 为 `.el-overlay-dialog[role=dialog] > .el-dialog`，且 Vue 会把隐藏弹窗残留在 DOM（height 0）——调试时须按可见性过滤。

## 遗留

- el-drawer 类（Web SSH 终端、新建应用侧滑表单）本身全高带内滚，未改动；
- 遵用户指示仅本地验证，**未部署 NAS**；NAS 升级时随下次同步生效。
