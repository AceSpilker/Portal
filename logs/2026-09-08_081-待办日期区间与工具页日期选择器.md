# 081 · 待办日期区间 + 工具页日期时间选择器升级

## 需求原意

1. 待办应该与日期绑定：支持**开始日期和结束日期**，在这个区间内日历上显示该待办（用户反馈现在"不知道和什么绑定"——快速添加固定绑定"今天"，与所选日期脱节）；
2. 全局检查所有涉及日期时间的组件：工具页的日期时间选择"用的好丑"，如果 Element Plus 没有合适的就自己封装。

## 现状与完成情况

### 待办区间（后端 + 前端）

| 层 | 改动 |
|---|---|
| 模型 | `todos` 表新增 `end_date DATE`（可空，索引）；`todo_date` 语义变为开始日期；轻量迁移补列 |
| API | TodoBody 增加 `end_date`；create/update 持久化并校验（结束 < 开始 → 422）；`_todo_out` 回显 |
| SchedulePanel | 快速添加**绑定当前选中日期**（原固定今天）；待办行显示日期区间（`09-10~09-12`）；点击标题打开**编辑弹窗**（标题 + el-date-picker daterange 起止 + 已完成开关 + 保存） |
| 日历 | 格子显示当日覆盖的待办数（☑ N）——区间内每天都标记 |

### 工具页时间戳转换

日期输入从裸 `el-input type="datetime-local"`（原生控件，观感差且各浏览器不一致）升级为 **el-date-picker type="datetime"**（value-format 保持原字符串格式，转换逻辑零改动）。

### 日期时间组件全局盘点

| 位置 | 组件 | 结论 |
|---|---|---|
| 事件弹窗日期 | el-input disabled（展示所选日） | 符合设计 |
| 事件时间 | el-time-select/el-input | 正常 |
| 设置·时区 | el-select | 正常 |
| 工具·时间戳转换 | **本次升级** el-date-picker datetime | ✅ |
| 待办编辑 | **本次新增** el-date-picker daterange | ✅ |
| 效率日历 | el-calendar | 正常 |
| 端口总览搜索等 | 文本输入 | 不涉及 |

未发现需要自封装的缺口（Element Plus 覆盖所有场景），暂不引入额外封装层。

- 后端：新增 `tests/test_todos_range.py` 2 例（区间创建回显、倒置 422）✅；全量 **232 passed / 2 skipped** ✅；ruff ✅（含 i18n 新键 v.todo_range_invalid）；
- 前端：vitest 57/57、build、eslint ✅；
- 本地浏览器实测：快速添加待办绑定**所选日期**（9/10）并显示区间文本；日历 9/8 显示 ☑4、9/10~9/12 显示 ☑1（区间覆盖）；工具页日期时间选择器渲染正常。
