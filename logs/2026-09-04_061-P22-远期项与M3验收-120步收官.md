## 已完成

### 22.1 企业登录（M01-12/13）
- **OIDC 授权码登录**：`GET /api/auth/oidc/authorize`（签名 state 防 CSRF，公开端点）+ `POST /api/auth/oidc/callback`（code 换 token → userinfo → 按 preferred_username 查找/**自动开通** role=user → 签发会话）；client_secret Fernet 加密存储；
- **LDAP 绑定登录**：`POST /api/auth/ldap/login`（bind_dn 模板可配，ldap3 绑定成功→自动开通；随机本地密码，日常认证走 LDAP）；配置 `GET/PUT /api/auth/enterprise`（密文+脱敏）；
- **公开配置扩展**：`/api/auth/config` 增加 oidc_enabled/ldap_enabled（登录页动态显示入口）；
- **Passkey/WebAuthn**：远期预留（需注册 ceremony 与凭据存储，设计见 feature-spec M01-12 注记）。

### 22.2 远期功能点（子集落地）
- **最近使用**（M02-8）：apps.last_opened_at 列 + `/apps/{id}/opened` + `GET /apps/recent`（Top6 首页 chips）；
- **DNS 查询**（M10-4）：`GET /api/tools/dns?host=` getaddrinfo A/AAAA；
- **日历订阅**（M13-6）：`GET /api/calendar/ics` RFC5545 子集导出（转义/UID/DTSTAMP）；
- **文本编辑**（M11-5）：`GET /files/text` + `POST /files/content`（≤256KB，白名单内）；
- **空间分析**（M11-7）：`GET /files/analyze`（子项大小 Top30，递归深度 3）；
- **AI 用量统计**（M05-15）：`GET /api/ai/usage?days=`（按日消息数/token 汇总）；
- **Webhook 出站**（M14-3）：由既有能力覆盖——Flow 事件触发器 + HTTP 动作即带签名的出站 Webhook（P14 已交付）；
- **远期保留**（明确不做并记录）：知识库（RAG）、图片理解（视觉模型依赖）、RSS 组件、快传、插件机制、移动专属布局（v1.4 已移除移动端）。
