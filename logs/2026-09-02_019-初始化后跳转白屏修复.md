# 工作日志 · 2026-09-02 · 019：初始化/登录后跳转白屏修复

> 记录人：ZCode ｜ 性质：缺陷修复（用户实测反馈）

---

## 需求（用户原意）

初始化向导创建管理员成功后，跳转到首页是白屏，必须手动刷新一次才能看到内容。

## 根因定位

1. `App.vue` 顶层 `<router-view>` 外包了 `<transition name="page" mode="out-in">`；
2. `LoginView` 是**多根组件**（AuroraBackground + .page + .copyright 三个根节点），Vue 明确要求 `<Transition>` 内必须是单根元素——多根时 out-in 的离开/进入编排失效，进入钩子丢失后新视图**永远插不回 DOM**；
3. 该状态会**毒化后续所有导航**（复现：任意两次客户端跳转后 `#app` 永久为空），只有整页刷新（初始渲染不走过渡）才能恢复；
4. 浏览器内实测复现：`/apps → /login → /apps` 两次跳转后 `#app.children === 0`，且无任何 JS 报错（静默失败，控制台不提示）。

## 修复

1. **`LoginView` 包单根容器** `.login-view`（AuroraBackground 为 fixed 定位，包裹无副作用）；
2. **移除顶层 `<transition mode="out-in">`**：该过渡纯装饰性，且 out-in 编排死锁是 Vue 已知问题类（后台标签页 / 快速连续跳转均可触发）。页面入场效果由各视图自身的 `fade-up` / `stagger` CSS 动画承担，观感不变；
3. 顺带清理 LoginView 中未使用的 `siteName` 死代码。

## 验证

- 复现脚本前后对比：修复前两次跳转后 `#app.children = 0`（白屏）；修复后**连续 5 次跨页跳转**（login→home→apps→settings→home）全部正常渲染；
- 前端 lint / vitest(5) / vue-tsc build 全绿。
