# 108 · 局域网页样式对齐全站（用户反馈）

## 需求原意

用户反馈局域网页与其它页面显示风格差别大：右侧内容区域没占满、页签显示
方式不同、下方结果区域的文字样式和布局不一致，要求全部统一。

## 原因

初版 LanView 用了 `tabs-card / ov-toolbar / stat-chip / table-fill /
state-pill` 这些类名，但这些类在 PortsView 里是 **scoped 样式**（非全局）——
我的文件里没有同款定义：根类还用了不存在的 `page-fill`；`.tabs-card` 缺
`flex:1 + :deep(el-tab-pane)` 撑满链（这是 100 号日志约定的全站撑满方案）；
state-pill 配色（light-9/1px 内边距）与全站（light-8/2px）不同；
RouterPanel/查看器在 `glass` 上又叠了 border/radius 形成双重描边。

## 完成情况（6 个文件）

- **LanView.vue**：根类改 `.lan-page`（同 ports-page 的 flex 列 + gap 14）；
  完整复制 PortsView 的 `.tabs-card`（flex:1/min-height:0/padding/12px 圆角 +
  `:deep` 三级撑满：header 不缩、content flex:1、tab-pane 100% 高内部滚动）
  与 `.ov-toolbar/.stat-chip/.table-fill/.state-pill(up/down/unknown)` 原样；
  设备详情抽屉补 PortsView 的 info-body/info-sec/info-well 同款。
- **DbPanel.vue**：根 flex:1 撑满页签、表格包 `.table-fill` + `height="100%"`
  （同端口页 monitors 页签），工具栏/胶囊全套同款。
- **RouterPanel.vue**：`glass sub-card` 去掉叠加的 border/背景（glass 已提供），
  改 lookup-card 范式（padding 12/14 + 12px 圆角）；el-empty 空态换成端口页
  的 `.empty` 文字样式；h4/kv 字号对齐。
- **Mysql/Minio/Redis 三个查看器**：stat-card 去双重描边；muted 色统一
  `--p-muted`；tab-toolbar 对齐 ov-toolbar（间距/换行/不收缩）。

## 测试结果

- 前端四关：vitest 57/57 ✅、eslint ✅、vue-tsc + build ✅（纯样式改动）；
- 浏览器实测（本地 dev，深色主题）三页签截图逐张检查：设备清单卡撑满视口、
  表格内部滚动无底部空白；路由器页三卡单描边统一；数据库服务页统计胶囊/
  工具栏/状态胶囊与端口监控页一致。

- 无（样式改动，无接口/契约变化）。
