# 092 · 知识库映射目录选择框

## 需求原意

用户在知识库新建「服务器目录」数据源时，映射目录路径要求**选择框**形式，不要手动输入。

## 完成情况

1. **后端** `GET /api/knowledge/local-dirs?path=`（管理员）：
   - `path` 为空 → 返回推荐挂载根（`/knowledge` 与 `DATA_DIR/knowledge`，存在者才列出）；
   - `path` 指定 → 返回该目录的一级子目录（绝对路径，供前端直接下钻）、上级路径与存在标记；
   - 不存在的路径返回 `exists:false`（不报错，选择框内提示）。
2. **前端**（KnowledgeView）：
   - 源管理弹窗中 local 路径输入框改**只读**，右侧「选择目录」按钮；
   - 选择框：推荐挂载点入口 + 「从根目录 / 开始浏览」→ 逐级点选下钻（📁 子目录列表、
     ⬆️ 返回上级、面包屑显示当前路径）→「选择此目录」回填。

## 测试结果

- 后端：全量 **254 passed / 2 skipped**（新增 local-dirs 用例），ruff ✅；
- 前端：vitest 57/57 ✅、eslint ✅、build ✅；
- 本地浏览器实测：选择框 → 从根目录下钻 / → tmp → kb-demo →「选择此目录」→ 路径回填 ✅。

## 说明

容器内可见目录仅限 compose 挂载项；NAS 上推荐统一挂到 `/knowledge/xxx`，
选择框首屏即会列出，无需翻根目录。
