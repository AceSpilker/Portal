## 发现的问题(按严重程度)

1. **【阻断·P7.4】新增用户必然失败(422)**:`UsersPanel.vue:160` 用户名输入框误用单向绑定 `:model-value="form.username"`(应为 `v-model`),输入永不写入表单,提交的 username 恒为空串,后端 `v.username_rule` 422:"Username must be 3-32 chars…"。且失败后输入框显示值被重置、弹窗不关闭。家庭用户新增流程完全不可用(后续禁用/重置密码等流程也因此无法端到端验证)。
2. **【缺陷·P7.4】危险操作失败无任何反馈**:`toggleStatus/resetPassword/kick`(UsersPanel.vue:74-102)对 API 错误无 catch——确认禁用自己被后端 self-guard(`err.user_self_action`)拒绝后,UI 无 toast,仅 console 未处理 rejection。对比 `save()`(69-71 行)有 catch+error toast。
3. **【缺陷·P7.5】UI 无访客开关**:设置中心 8 个面板均无 guest.enabled 开关,访客模式只能改库/API 开启,功能不可发现。
4. **【i18n】英文界面弹中文错误**:WoL 非法 MAC 时 toast 显示中文"MAC 地址格式不正确"——`backend/app/api/v1/tools.py:47/:81` BizError 消息硬编码中文,未走 `app/core/i18n.py` 的 t()(MESSAGES 亦无对应 key)。同页面其余消息均正确切换。
5. **【i18n】Element Plus 空状态未本地化**:访问方式面板等 el-empty 显示内置英文"No Data"(中文界面下同样是英文)。
6. **【显示】监控页磁盘分区行文字挤压**:macOS 超长挂载名(/System/Volumes/…)与容量/百分比挤在一行,出现"…iSCPreboot100.7 MB / 500.0 MB25.6%"式粘连与孤行换行;建议挂载名 ellipsis + 容量列固定宽。
