# 047 · P11 端口监控★(监听清单/探活状态机/变更告警/关联/看板)

## 需求原意

连续开发 7 个阶段(P11~P17)的第 1 个:**P11 · 端口监控 ★**(M18-1~7,5 步)。以"端口"为中心的网络层监控,回答"服务挂了还是端口不通"。

## 完成情况

### 11.1 监听清单 + 11.5 检索
- `GET /api/ports/listen`(A):psutil.net_connections 过滤 LISTEN(协议/地址/端口/PID/进程/命令行);**macOS 非 root 整表权限抛 PermissionError → 按仓库多平台约定回退系统 `lsof -nP -i -sTCP:LISTEN` 解析**(进程名兜底 lsof 首列命令名);`GET /api/ports/lookup?port=`(A)同构回退;
- 前端「监听清单」tab + 顶栏占用检索(端口号 → 占用进程/命令行/用户)。

### 11.2 探活项 + 状态机 + 11.3 变更告警
- 新模型 `port_monitors`(name/host/port/app_id/interval/enabled/state/last_*)与 `port_events`(翻转才记录,索引 monitor_id+created_at);
- `services/ports.py`:TCP 探测(asyncio.open_connection,3s 超时)→ 翻转才记事件并 **dispatch port_down/port_up(P9 出口,level down=warn/up=info,分钟粒度去重)**,WS 广播 `port_status`;调度 `port_probe` 每 10s 巡检到期项;
- 端点:监控项 CRUD(A 读 M 写,app_id 校验存在)、批量导入、事件流水(附监控项名/关联应用名)。

### 11.4 应用关联 + 11.5 看板
- 监控项可关联门户应用(列表回传 app_name,点击跳应用页);
- 新页面「/ports」(侧栏新增「端口」导航):总览看板(**异常置顶排序** + 全部/异常/正常筛选)、监控项表格(状态徽章/延迟/间隔/启停/编辑/删除)、事件流水;批量导入对话框(`host:port` 或 `名称|host:port`,同 host+port 去重,返回 created/skipped)。

## 关键决策

1. **macOS 非 root 回退 lsof**:psutil 整表连接权限是 macOS 硬限制;按 CLAUDE.md「多平台分支必须写明依据与回退行为」——psutil 优先(Linux NAS 主场景),lsof 回退(macOS 开发机),都失败返回空清单;
2. **翻转才落事件** + 分钟粒度 dedup:与 M07 探活同构,避免探测抖动刷屏;
3. **权限口径按契约**:清单/检索/流水 A(任意登录用户),写操作 M;
4. WS 事件 type=port_status,前端本轮未接(看板 10s 轮询已够,P14 Flow/实时性需求出现再接)。
