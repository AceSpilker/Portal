## 过程中发现并修复

1. **FastAPI 路由顺序**:`/apps/recycle-bin`、`/apps/templates` 固定路径被后注册检查顺序中在前的 `/apps/{app_id}` 捕获 → 移至参数路由之前;
2. `from_template` 局部变量 `t` 遮蔽 i18n 翻译函数(ruff F821 暴露)→ 改名 `tpl`;
3. `tags` 双重 JSON 编码(App.tags 列为 JSON 类型)→ 直接传 list;
4. **既有测试顺序脆弱性被暴露**:p2 的 `test_17` round-trip 断言(`export1 == export2`)在"库内存在跨模块软删残留"时不稳定——p15 全家桶残留的软删模板应用触发 → 在 p15 测试尾部 **purge 自身软删数据**修复,连续三次全量 166 全绿。
