# 101 · 待办清单交互优化：整行编辑 + 日期带年份 + 行内改日期

## 需求原意

用户反馈待办清单三点（效率画面侧栏）：

1. 目前只有**点击待办名称**才弹编辑对话框——改为**点击整行即可编辑**，
   复选框与删除按钮除外；
2. 待办行显示的日期部分要**带上年份**（原 `MM-DD`）；
3. 单独**点击日期**时，不弹编辑框也能**直接改日期**。

## 完成情况（纯前端，`SchedulePanel.vue` + i18n）

### 1. 整行点击编辑

- `@click="openTodoEdit(td)"` 上移到待办行 `<li>`；
- 复选框加 `@click.stop`（此前点击复选框其实也会连带弹编辑框，顺带修复）、
  删除按钮改 `@click.stop="removeTodo(td)"`——两者均不再触发行编辑；
- 名称上的原 `@click` 移除（整行接管），悬停提示保留。

### 2. 日期带年份

- 单日：`2026-09-11`；区间：`2026-09-14~2026-09-18`（不再截掉年份）。

### 3. 行内改日期（不弹编辑框）

- 点击日期文字 → 原位切换为 `el-date-picker type="daterange"`（value-format
  `YYYY-MM-DD`），经其 ref 暴露的 `handleOpen()` **自动展开双月面板**——
  无需二次点击输入框；
- 选完起止日期触发 `change` → `updateTodo` 保存 → 刷新列表；面板自动关闭
  （`visible-change(false)`）后还原为日期文字；点击面板外取消同样还原；
- 日历格待办缩略（099）随新区间实时重排；
- 无日期的待办不渲染日期文字（保持原状，编辑框内仍可设置）。

- 前端：vitest **57/57** ✅、eslint ✅、vue-tsc + build ✅；
- 后端：全量 **257 passed / 2 skipped** ✅、ruff ✅（未动后端）；
- **浏览器实测**（临时实例 8010/5180，UI 全流程初始化管理员）：
  - 整行点击"短待办"→ 弹出「编辑待办」框 ✅；
  - 点击日期 `2026-09-11` → 直接展开双月面板（无编辑框），选 9/14~9/18 后
    行内显示 `2026-09-14~2026-09-18`、日历 14~18 格同步出现缩略 ✅；
  - 点复选框 → 仅切换完成态（划线+移入已完成+计数 2→1），无编辑框 ✅；
  - 点删除 → 直接删除（该按钮原有免确认直删行为保持），无编辑框 ✅；
- 无接口/表/枚举变更，契约文档无需同步。

## 关键决策

- 行内改日期选 `el-date-picker` 原位替换 + `handleOpen()` 自动展开，而非
  popover 包一层：少一层浮层、面板关闭事件（visible-change）天然就是
  "结束行内编辑"的信号，交互闭环最短；
- `change` 回调直接闭包捕获行 `td`，不依赖 `dateEditId` 状态查行——规避
  `visible-change(false)` 先于 `change` 触发时状态已被清空的时序坑；
- 已完成/未完成两个 v-for 块保持既有复制风格，未抽组件（改动最小化）。

## 遗留

- 删除待办仍是免确认直删（历史行为），如需加确认提示另行安排；
- 无日期待办行内不可改日期（其本就不上日历，编辑框内可设置日期）。
