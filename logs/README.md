# Portal · 工作日志说明（logs/README.md）

本目录存放 Portal 项目的**工作过程日志**：每次用户提出的需求、以及实际完成的工作，都会记录在这里，方便回顾项目的演进过程。

## 命名规则

```
YYYY-MM-DD_NNN-主题.md
```

- `YYYY-MM-DD`：日志对应的日期
- `NNN`：当日序号，从 `001` 递增
- `主题`：本次任务的简短描述（中文）

示例：`2026-09-01_001-项目启动与功能详述.md`

## 单篇日志的固定结构

1. **需求**：用户当时提出的要求（尽量保留原意）
2. **完成情况**：实际做了什么、产出/修改了哪些文件
3. **关键决策**：过程中定下的方案与约定
4. **遗留/下一步**：未完成或有待确认的事项
