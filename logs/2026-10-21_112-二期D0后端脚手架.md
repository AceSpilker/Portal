# 112 · 二期 D0：后端脚手架（Django 5.2 + Ninja + 加密中间件移植）

## 需求原意

用户："你现在可以按照二期的开发计划进行开发，记得同步开发状态"——按
phase2/doc/dev-plan.html 从 D0.1 开始执行，完成一步同步一步状态。

## 实现（D0.1–D0.8 完成，D0.9 进行中）

1. **D0.1 工程**：phase2/backend Django 5.2.18 工程（config/settings|asgi|urls|wsgi、
   manage.py）；环境变量键名与一期一致（SECRET_KEY/DATA_DIR/ENCRYPT_ENABLED…）；
   无 admin/session/auth；SQLite→DATA_DIR/data.db（WAL）。
2. **D0.2 Ninja 接入**：config/api.py 聚合器 + apps/core/response.py——信封
   **code=200/msg**（ADP 原生形态，业务错误码 1001–5006 同一期）；BizError 与
   2001 校验异常处理器（中文拼接文案逻辑 + FIELD_LABELS 全量移植）；DEBUG 才开
   /api/docs。**差异记录**：django-ninja 1.7.1 已移除 `csrf` 构造参数；端点首参
   必须为 `request`（与 FastAPI 不同）。
3. **D0.3 加密链路**：TransportEncryptionMiddleware（纯 ASGI）+ crypto.py 引擎 +
   /api/crypto/public-key、/api/crypto/handshake 逐行移植（协议/豁免清单/1100/1101/
   1102/nonce LRU/RSA pem 持久化全部不变）。**两处 ASGI 移植差异**（已修，均有用例）：
   ① Django ASGI 读完请求体后会再 receive() 监听断连——receive_decrypted 改为
   有状态（首调解密体、后续转发原始通道），否则 "Invalid ASGI message"；
   ② Django 响应头名保留大小写（Content-Type），Starlette 恒小写——封包判型
   改小写归一化查找。
4. **D0.4 health**：/api/health（公开豁免；initialized 用裸 SQL count users，
   D1 模型接管前表缺失视为 0）。
5. **D0.5 i18n**：i18n.py（448 行 MESSAGES，zh-CN/en）整文件移植 + Django
   LocaleMiddleware（Accept-Language→contextvar）。
6. **D0.6 stores/secret_box**：MemoryStore/RedisStore/StoreManager（降级/回切）
   移植，sync_log 事件在 D7 前静默旁路；Fernet secret_box 移植（data/keys/sync.key）。
7. **D0.7 顶层骨架**：/icons 静态托管（缺目录 404 JSON）+ /tunnel、/files/raw
   占位（501，D5/D6 落地）+ 可选本地直连 SPA 视图（FRONTEND_DIST 配置时）。
8. **D0.8 测试脚手架**：pytest-django + httpx ASGITransport 全栈客户端（加密
   中间件在 Django 之外，Django test Client 不可达）；test_health 5 例（ADP 信封
   形态/未知 API JSON 404/2001 中英双语/探针）+ test_crypto 7 例（FakeSession
   握手/信封往返/1100/1101 重放/1102 坏信封/豁免/ENC 头）。**12 用例全绿 + ruff 干净 = 关卡 A 通过**。
   **决策记录**：① pytest-django 在 initial-conftest 阶段即加载 settings，env
   引导来不及——改用 config/test_settings.py（独立临时 DATA_DIR + ENCRYPT=False）
   作为 pytest.ini 的 DJANGO_SETTINGS_MODULE；② 加密开关读取改为
   _env_first("ENCRYPT_ENABLED","SECURITY__ENCRYPT_ENABLED")（一期 AliasChoices
   语义），修复 or 短路吞掉 false 的 bug。
9. **D0.9 前端迁入（进行中）**：frontend-artdesign → phase2/frontend（上游 .git
   已删，README/注释记录上游 f3aaf58/v3.0.2）；.env 三件改写（端口 5174、
   VITE_BASE_URL=/portal/、dev 代理→8001、prod VITE_API_URL=/）；vite.config.ts
   代理扩到四条（/api /ws(ws) /icons /tunnel）；pnpm install 进行中。
10. **关卡 B 后端侧冒烟**：uvicorn 8001 实测——/api/health 返回
    `{"code":200,"msg":"ok",data:{...initialized:false}}`（ADP 信封 Live ✓）、
    /api/crypto/public-key 下发 RSA 公钥（默认加密开）、非豁免路径无会话→1100。

## 决策

- **dev 端口改为 5175**：5174 被本机另一运行中项目占用（IPv4 已绑，vite 仅
  得 IPv6，浏览器实际打到旧服务）——不动用户进程，二期前端固定 5175；
  dev-plan/迁移方案文档端口引用已同步。
- 品牌已替换（index.html 标题 + config name=Portal），登录页 title 实测
  "登录 - Portal"。
- 测试环境隔离用"测试 settings 模块"而非 conftest env 引导（pytest-django 加载
  时序决定，见上）。
- 加密中间件两处 Django 适配（receive 有状态 + 头名小写归一）是框架差异而非
  协议变化，前端无感知；一期代码保持不动。
