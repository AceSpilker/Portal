## 需求（用户原意）

## 完成情况

### 1. 国际化（i18n，中文默认 + English）

**前端**：

- 引入 vue-i18n v11（Composition API）；语言包 `src/locales/zh-CN.ts` / `en.ts` 按模块分组（common/request/nav/login/home/apps/settings/iconPicker）；
- 五大视图 + AppLayout + IconPicker 全部文案改走 `t()`，含占位符、下拉选项、确认弹窗、ElMessage 提示；
- 顶栏新增语言下拉（🌐 中文 / English）：切换写 `localStorage.portal.locale`（默认 zh-CN）、即时生效无需刷新；Element Plus 组件内置文案经 `ElConfigProvider` 响应式跟随；
- axios 拦截器为每个请求附带 `Accept-Language`，驱动后端文案语言。

**后端**：

- 新增 `app/core/i18n.py`：contextvar 保存请求语言 + 消息表 `MESSAGES`（约 60 个 key 的双语字典）+ `t(key, **kwargs)`（缺失键回退 zh-CN）；
- `main.py` 新增 HTTP 中间件：读 `Accept-Language`（`en*` → en）写入 contextvar；
- 全部 BizError / ok 提示 / pydantic 校验器文案 / 422 参数校验格式化（含字段名标签双语）均接入 `t()`。

### 2. 全局页面动画

- 根因：此前只有 HomeView 用了 `fade-up/stagger` 动画类；且顶层路由过渡已因白屏死锁移除（日志 019）；
- 方案：`AppLayout` 内以 `router-view v-slot + :key="route.fullPath"` 的包裹层承载纯 CSS 动画 `page-in`（透明度 0→1 + 上移 10px，0.35s）——**keyed 元素替换即重放动画**，所有路由页面全局生效，且无 transition 组件的编排死锁风险；视图内部仍保留各自 `fade-up/stagger` 逐项动画。

## 关键决策

1. **语言偏好存 localStorage（按浏览器）而非用户表**：i18n 是界面偏好，登录前（登录/初始化页）也需要生效；站点级默认语言（general.language）留作后续访客默认值策略；
2. **后端 contextvar + 请求中间件**：让所有校验器/服务函数无侵入拿到当前语言，不需要层层传参；
3. **动画用 keyed 元素重放 CSS 动画，不用 transition 组件**：规避 019 白屏死锁同类风险，动画与路由解耦。
