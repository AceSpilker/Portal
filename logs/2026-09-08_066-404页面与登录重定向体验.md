# 066 · 404 页面与未登录访问重定向体验补齐

## 需求原意

用户指出系统缺少 404 页面与错误页面：错误场景直接显示裸 JSON `{"detail":"Not Found"}`；通过路由直达其他页面（未登录）应重定向回登录页并给出提示信息，而不是无感知跳转。

## 现状分析

- 后端 `/api/*` 未知路径返回 JSON 404 属正确契约；页面路径的裸 404 已由 065 的 `_SpaStaticFiles` 回退修复，但前端 Vue Router **没有 catch-all 兜底路由**——未知路径回退到 index.html 后路由无匹配，渲染白屏；
- 登录守卫 `beforeEach` 对未登录直达受保护路由**静默跳转** login，无任何提示，用户不知道发生了什么。

## 完成情况

**已实现并部署（提交见 git log）。**

1. **新增 `views/NotFoundView.vue`**：404 兜底页，视觉与登录页同语言（AuroraBackground + glass 卡片 + 渐变 404 大字 + fade-up 动效），提供"返回首页 / 返回上一页"；独立整页不套 AppLayout，未登录访问同样成立；
2. **路由 catch-all**：`/:pathMatch(.*)*` → not-found（public），未知路径不再白屏；
3. **守卫提示**：未登录直达受保护路由 → `ElMessage.warning("请先登录后访问该页面")` + 重定向 login；
4. **i18n**：zh-CN/en 新增 `notFound.title/desc/backHome/back` 与 `request.loginRequired`；
5. **回归测试 `__tests__/router.spec.ts` 4 例**：未知单级/多级路径兜底、未登录重定向、已登录正常进入。

## 测试结果

- vitest **52/52**（新增 4 例）；`npm run build`（含 vue-tsc）✅；eslint ✅；
- NAS 重建后浏览器实测：未知路由渲染 404 页、未登录直达 /apps 弹提示并回登录页、登录后恢复正常（结果见下）。

## 关键决策

1. 404 页设为 `public`：未登录访问未知路径优先展示 404 页（而非被守卫弹回登录），语义更真实；从 404 页点"返回首页"再由守卫接管登录引导，行为闭环；
2. 守卫提示放在路由层而非请求层：请求层的 401 已有"登录已失效"提示（request.ts），两处语义不同不合并。

## 遗留

- 登录成功后不回跳原目标页（redirect query），如需要可在守卫带 `redirect` 参数实现；
- 初始化页"加密传输已启用"文案与 HTTP 明文部署不符（065 遗留 #11），仍待随开关状态切换。
