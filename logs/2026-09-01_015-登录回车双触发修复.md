# 工作日志 · 2026-09-01 · 015：登录回车双触发修复与错误提示优化

## 需求（用户原意）

登录页面密码框中按下回车，会触发两次登录接口。

## 根因

登录提交按钮的原生类型是 `submit`，密码框上又绑定了 `@keyup.enter="handleLogin"`。回车时两个路径同时触发：

1. 浏览器表单**隐式提交**（有 submit 按钮时回车即提交）→ `@submit.prevent` → 第 1 次；
2. 输入框 `@keyup.enter` → 第 2 次。

## 修复（LoginView.vue）

1. **统一提交入口**：移除输入框上的 `@keyup.enter`，回车交给表单原生隐式提交处理；按钮保留 `native-type="submit"` 并移除多余 `@click`；
2. **防重复守卫**：`handleLogin / handleInit` 入口增加 `if (submitting.value) return`，请求进行中重复触发直接忽略；
3. 初始化向导（confirm 回车）同步修复。

## 验证（浏览器实测）

- 密码框按回车：`/api/auth/login` 请求数 **1 次**（修复前 2 次）✅；
- 点击按钮：同样 1 次 ✅；
- ESLint / build 通过。

## 顺带优化

axios 错误拦截器优先取后端统一响应的 `message`（如"用户名或密码错误"），不再显示 "Request failed with status code 401" 这类生硬文案。
