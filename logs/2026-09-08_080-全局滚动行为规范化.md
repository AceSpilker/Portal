# 080 · 全局滚动行为规范化（设置页二级菜单 + 滚动链约束）

## 需求原意

用户反馈：系统设置的二级菜单不要整体垂直滚动，只有二级菜单内容应该滚动；并要求全局检查各种滚动行为，消除不合理之处。

## 排查结论（实测数据）

设置页的 flex 布局本身是健康的——在 1280×700 实测：菜单（869/602 内滚）、面板（内容自适应）、文档（不滚）各司其职。用户感受到的"整体乱滚"实际是**滚动链（scroll chaining）**：内层容器（面板/菜单/弹窗正文）滚到底之后，继续滚动会把滚动"接力"给外层祖先，视觉上就是"整个页面跟着滚"。

## 完成情况

| 改动 | 效果 |
|---|---|
| 设置页 `.menu` / `.panel` 加 `overscroll-behavior: contain` | 菜单或面板滚到底后，滚动不再接力给页面/彼此——**面板滚动时二级菜单纹丝不动**（实测 menuTop 恒定 74） |
| 全局 `styles/index.css`：`.el-dialog__body / .el-drawer__body / .el-tabs__content / .el-table__body-wrapper` 加 `overscroll-behavior: contain` | 所有弹窗/抽屉/标签内容滚到底不再带动页面 |
| `LogsView` 根容器同样加 contain | 日志中心内滚隔离 |

## 测试结果

- 图标库长面板滚动：面板内容滚动、二级菜单位置恒定（74px）✅；
- vitest 57/57、build、eslint ✅；
- 本地实测交互正常（未部署 NAS，遵既定指示）。

## 各页面滚动模型（全局复查结论）

| 页面/组件 | 滚动模型 | 状态 |
|---|---|---|
| 应用外壳 .shell | 永不滚动（overflow hidden） | ✅ |
| 监控/效率/首页等长页 | 窗口级自然滚动（内容型页面，合理） | ✅ |
| 设置页 | 二级菜单与右侧面板各自内滚 + contain | ✅ 本次 |
| 日志中心 | 视口高度约束 + 表格内滚（075/076） | ✅ |
| 端口总览 | 表格固定 480 内滚 | ✅ |
| 所有弹窗 | 限高视口 + 正文内滚（075） | ✅ 本次加 contain |
| 抽屉（SSH 终端等） | 自带内滚 + contain | ✅ 本次 |
