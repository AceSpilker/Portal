## 需求（用户原意）

系统不搞移动端适配了，就是电脑上看的 Web 画面；顶多把 Web 显示再优化一下，整体好好看一看。

## 需求变更落地（文档先行）

- **feature-spec 升 v1.6**：移除 M16-1（全站响应式/触控目标）、3（底部导航）、5（移动专属布局）、7（安全区与手势）；保留 2/4（PWA，调整为桌面浏览器安装场景）与 6（暗色跟随，已实现并移入 M02-18）；模块规模 7 → 2 点，总功能点 225 → 220；
- **dev-plan 升 v1.4**：4.8「首页移动端适配」移除（➖ 标注），总步骤 118 → 117、当前进度 46 / 117；P17.4 PWA 注明桌面安装场景；
- **M1 验收场景联动调整**：原"浏览器窗口缩到手机宽度磁贴单列"验收点随 4.8 移除作废。

## 代码清理

1. **AppLayout**：移除底部 Tab 导航（模板/样式/媒体查询）、`<768px` 移动端媒体查询块（侧栏隐藏/安全区 padding/移动端登出按钮）、`mobile` class 分支；**保留窄窗口（<1080px）侧栏折叠为图标栏**——这是桌面拖窄窗口的合理行为，改由 `useMediaQuery` 直接实现，不再依赖移动端判定；
2. **组合式函数**：删除 `useIsMobile.ts`（含 isMobile/isTablet 导出）；
3. **弹窗宽度**：6 处 `isMobile ? '94%' : '520px'` 类三元统一为固定桌面宽度（App/EntryPopup/AppsManage×2/Settings/AccessPanel/CommandPalette）；
4. **HomeView**：磁贴拖拽不再因移动端禁用；
5. **MonitorView**：移除与 auto-fit 网格重复的 768px 媒体查询；
6. 语言包无孤儿键（tab 底部导航复用的是 nav.* 通用键）。

## Web 桌面显示优化保留项

- 弹窗/抽屉固定桌面宽度（520~620px），不再随窗口宽度抖动；
- 监控页卡片网格 `repeat(auto-fit, minmax(340px, 1fr))`：桌面拖窄窗口自动降列；
- 侧栏 <1080px 折叠图标栏：桌面分屏/半屏窗口的合理形态。
