## 任务 1：提出项目并要求输出总体设计方案

**需求**（用户原意）：想做一个部署在 NAS 上的门户系统。前端用 Vue + TS，后端用 Python，最终打包为一个 Docker 容器。核心功能：进入门户可登录；登录后首页展示可点击跳转的 icon 标签；支持为每个服务配置多种访问方式（域名访问、内网 IP 访问、公司 SSH 访问等），并有对应设置页面；其余功能自行设计，可能包含 AI 功能、Flow 流等。先输出设计方案（MD 和 HTML 文件）供评审。

**完成情况**：

- 完成《Portal 总体设计方案》v0.1，产出：
  - `docs/design-proposal.md`
  - `docs/design-proposal.html`（纯静态单文件，左侧目录导航）
- 方案要点：Vue3 + TS / FastAPI + SQLite 单容器部署；多访问方式智能解析（网络环境档案 + CIDR 识别 + 入口优先级）；AI 助手、Flow 自动化、监控探活、通知中心等模块设计；
- 用 Edge 无头浏览器整页渲染并分段截图验证了 HTML 排版，确认无布局问题后清理了临时文件。

**关键决策**：

1. 前后端打包进同一镜像，FastAPI 通过 StaticFiles 托管前端产物，NAS 部署最简；
2. "多访问方式"确定为差异化核心：每个应用挂多个入口（domain/lan/ssh/vpn/custom），按"网络环境档案"自动推荐最佳入口；
3. SSH 公司场景分两阶段：M1 生成 `ssh -L` 本地命令，M2 后端 asyncssh 托管隧道；
4. 方案末尾列出 6 个待确认问题（NAS 型号 / 使用人数 / AI 接入来源 / SSH 场景 / UI 组件库 / Flow 首版形态）。
