# 064 · NAS 实机缺陷修复：HTTP 访问下首次初始化崩溃（WebCrypto 不可用）

## 需求原意

用户在 NAS 部署实例（http://192.168.5.88:8080）首次创建管理员时报错：`Cannot read properties of undefined (reading 'generateKey')`，初始化流程中断。

## 根因

`secure.ts` 握手用 `crypto.subtle.generateKey` 生成 AES-256 会话密钥，而**浏览器只在安全上下文（HTTPS / localhost）暴露 `crypto.subtle`**。局域网裸 IP HTTP 访问时它是 `undefined`，一进初始化/登录即崩。本地开发与测试全部走 localhost（安全上下文），因此 P24 上线至今未暴露。本质是 P24 传输加密对"HTTP 局域网部署"这一 NAS 主流形态没有降级路径。

## 完成情况

**已修复并重新部署，链路验证通过（提交 4371f14）。**

| 改动 | 内容 |
|---|---|
| `frontend/src/api/secure.ts` | 检测非安全上下文 → **明文降级模式**：跳过握手，`ensureSession` 直接返回，`encryptBody`/`decryptBody`/`encryptHeaderValue` 原样透传（后三者原本就按 `!session` 降级，仅 `encryptHeaderValue` 需补透传分支）；新增 `isPlaintextTransport()` |
| `frontend/src/api/request.ts` | 明文模式下后端仍开加密（1100）时，不再无意义重试，直接给出部署错配的明确指引文案 |
| `frontend/src/App.vue` | 明文模式启动时一次性 ElNotification 告知"HTTP 访问、传输未加密"（8s 自动消失，诚实告知不静默） |
| `locales/zh-CN.ts` / `en.ts` | 新增 `request.plainTitle / plainTransport / plainConflict` |
| `docker-compose.yml` | 注释说明 `ENCRYPT_ENABLED=false` 适用于 HTTP 局域网部署 |
| NAS override | `ENCRYPT_ENABLED=false`（中间件整体旁路），SECRET_KEY/监控挂载不变 |

## 测试结果

- 前端关卡：vitest **48/48**、`npm run build`（含 vue-tsc）✅、eslint ✅；
- NAS 实机：重建后容器 healthy；`docker exec` 确认 `ENCRYPT_ENABLED=false` 生效；
- **关键链路实测**：明文 `POST /api/auth/init`（无会话头、无信封——即新前端在明文模式发出的原始形态）返回业务校验错误 `2001 参数校验失败：用户名/密码必填`，不再是中间件 `1100 secure session required`，证明降级链路端到端可用；
- 线上已切换新构建产物（`index-BqkTVBnZ.js`）。

## 关键决策

1. **关闭传输加密而非上 HTTPS**：WebCrypto 在 HTTP 下本就不可用，P24 对浏览器流量在 HTTP 形态下从来无法生效，关掉不损失实际安全性；家庭局域网明文是可接受形态。若用户后续需要加密，正路是 DSM 反向代理 + 证书上 HTTPS，届时去掉 `ENCRYPT_ENABLED=false` 即可（前端在安全上下文自动恢复加密会话）。
2. **前端自动降级而非报错阻断**：NAS 门户的核心场景就是局域网 HTTP，明文降级 + 明确提示比强制 HTTPS 更贴合产品定位；同时保留错配检测（明文前端 × 加密后端）的清晰报错。
3. 教训入 CLAUDE.md 候选：涉浏览器 API 的模块，部署形态差异（HTTP/HTTPS、IP/域名）要在契约文档标注环境约束——本次已在 docker-compose.yml 注释与 api-spec §7 语义内说明，未改接口契约。

## 遗留

- 用户可重新执行首次初始化（创建管理员）；页面会看到一次"明文传输"提示，属预期行为；
- P24 文档（api-spec §7）可补一句"HTTP 部署需 ENCRYPT_ENABLED=false"的部署约束，属文档补强，未阻塞；
- 如未来要加密上 HTTPS：DSM 控制面板新增反向代理 + 证书，去掉 override 中的 `ENCRYPT_ENABLED=false` 并重建。
