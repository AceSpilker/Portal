# 048 · P12 Docker 容器管理基础(可选模块)

## 需求原意

连续开发 7 个阶段的第 2 个:**P12 · Docker 容器管理基础**(M08-1~4,3 步,可选模块——默认关闭、需挂载 docker.sock)。

## 完成情况

### 12.1 接入与列表
- 开关:`settings.docker_sock_enabled`(env `DOCKER_SOCK_ENABLED`,compose 注释已预留)——默认 False;
- `services/docker_svc.py`:httpx UDS 封装 Docker Engine API(transport 可注入供单测);`GET /api/docker/containers`(M):全部容器(含停止)+ 运行中附带 CPU%/内存占用(stats 合并),**运行中排前**;
- `GET /api/docker/status`(A):前端导航动态显示——**未启用时导航隐藏、API 503、系统零报错(P12 退出标准)**。

### 12.2 生命周期操作
- `POST /api/docker/containers/{name}/{op}`(start/stop/restart,M):确认弹窗(前端)+ **审计日志**(docker_op,IP);
- 审计服务下沉:`app/services/audit.py`(write_audit/client_ip),users.py 与 docker.py 共用。

### 12.3 日志与详情
- `GET /api/docker/containers/{name}/logs?tail=`(M):尾部 1~1000 行,**清洗 Engine API 多路复用帧头**(非 tty 容器 8 字节头);前端对话框 4s 轮询 + 自动滚底;
- `GET /api/docker/containers/{name}/detail`(M):端口映射/卷挂载/环境变量——**敏感值脱敏**(KEY 命中 token/secret/pass/pwd/key/credential → 值打码 ******)。

## 测试结果

- 后端:`pytest -q` **150 passed**(145+5:假 Engine MockTransport 列表与占用换算/脱敏/日志帧清洗/restart 审计与 404/未启用 503);ruff 通过;
- 前端:build/lint/vitest 48 全绿;i18n 609=609;
- **浏览器端到端**(带 `DOCKER_SOCK_ENABLED=true` 重启后端实测):①默认关闭 → 「容器」导航隐藏、零报错(退出标准 ✓);②启用后列表与 docker ps 一致(MySQL 467.7MB·6% / Redis 23.2MB,Up 2 hours);③重启 Redis 弹确认框 → 执行成功 → **容器日志显示重启后的新启动记录**;④MySQL 详情:`MYSQL_ROOT_PASSWORD=******` 脱敏无泄漏、端口映射 3306 正确;⑤审计表新增「容器 Redis 执行 restart」;⑥验证后已恢复后端为默认关闭状态。

## 关键决策

1. **审计服务下沉** services/audit.py 而非复制逻辑(users.py 同步改为导入,行为不变);
2. **日志多路复用帧清洗**为尽力而为:非 tty 容器返回 8 字节帧头,按前缀裁剪;tty 容器原样;
3. 敏感词匹配用 KEY 名包含判断(误报率可接受,漏报风险低于值匹配);
4. 测试用 `svc.enabled` monkeypatch 绕过真实 sock 依赖,transport 走 MockTransport——不要求 CI 环境有 Docker;
5. **验证后恢复默认关闭**:开关属部署决策(NAS compose 中开启),不替用户持久化。
