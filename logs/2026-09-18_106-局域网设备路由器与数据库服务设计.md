# 106 · 局域网设备/路由器与数据库服务两模块设计方案（纯文档，未编码）

## 需求原意

用户提出两个新模块需求，要求**先出设计方案**并嵌入 docs 文档体系：

1. **局域网路由器设备检测**：能发现局域网中的路由器，点进去看路由器信息
   及各种连接信息；
2. **局域网数据库服务发现**：搜索局域网内有哪些数据库服务（MySQL、Redis、
   MinIO 等），能登录进对应服务**只查看、不编辑**。

## 现状结论（设计前梳理）

- 仓库此前**不存在任何网段扫描/设备发现实现**：feature-spec M10-2「局域网
  设备发现」是规划未落地项；现有网络能力 = CIDR 环境档案匹配 + host:port
  TCP 探活 + 纯标准库 SNMP v2c GET（services/snmp.py，Agent 模块在用）。
- 可复用资产：`connectivity.probe_apps` 的 Semaphore(16) 并发探测范式、
  `core/secret_box.py` Fernet 加密（redis/mysql/tunnels/知识库 git 四处在
  用）、`port_names.py` 端口语义词典、aiomysql + redis-py 依赖已存在；
  **无 minio SDK、无 ICMP 库**（设计上主动规避，容器无 CAP_NET_RAW 也能跑）。

## 方案要点（详见四份文档）

- **M19 局域网设备与路由器 ★（10 功能点 / P26 五步）**：
  - 存活判定 = 并发 TCP connect（`lan.probe_ports` 可配）命中 或 ARP 邻居表
    存在记录（Linux 读 /proc/net/arp，Docker 挂 HOST_PROC，macOS/Windows
    `arp -a`），**不用 ICMP、不提权、零新增依赖**；
  - 设备指纹：反向 DNS（线程池+超时）+ MAC OUI 内置厂商库 + 端口特征 →
    device_type（router/nas/printer/iot/host/db）；
  - 路由器 = 默认网关 + UPnP IGD（SSDP M-SEARCH → rootDesc.xml 型号/固件 →
    GetExternalIPAddress/GetStatusInfo WAN 状态，标准库 UDP+XML）+ 端口特征
    投票；SNMP 可选增强 ifTable 双采样接口速率与路由器侧 ipNetToMedia 在线
    设备（community Fernet 加密，未配置降级本机 ARP 视角并明示）；
  - 设备上下线事件走既有通知路由 + WS；一键建端口监控项 / WoL 目标。
- **M20 局域网数据库服务（9 功能点 / P27 六步）**：
  - 9 类端口握手指纹：MySQL greeting 包（零凭据拿版本）/ Redis PING·INFO /
    MinIO health+Server 头 / PG SSLRequest / Mongo hello / ES GET / Memcached /
    etcd / ClickHouse；
  - 凭据表 db_credentials（Fernet 加密、`password_set` 脱敏、空密码=保持原值，
    SSH 凭据同范式），按 host:port 自动关联发现的服务；
  - **只读查看器**全部服务端白名单固定查询、无任意 SQL 输入：MySQL
    概览/变量/库表/进程列表（aiomysql）；Redis INFO/SCAN 键浏览（禁 KEYS）/
    键值预览（4KB 截断+二进制 hex）/慢日志（写命令不进代码路径）；MinIO
    桶/对象浏览 + 5 分钟预签名下载（httpx + SigV4 手工签名，**不引入
    minio SDK**）；
  - 权限分层：清单/概览 A，数据库内容级 M，扫描/凭据管理 M。
- **共用安全边界**：目标限私网 CIDR 白名单（含 127.0.0.1；公网目标 4006）、
  扫描互斥 4005、并发 128 上限、审计覆盖。

## 关键决策

1. **不引入 ICMP/ping 库与 minio SDK**——TCP+ARP 判活 + SigV4 手工签名，
   保持"零新增后端依赖"，与 P23/P25"客户机已有服务仅需配置"的既有基调一致；
2. **只读 = 白名单固定视图**而非"只读账号"假设——家庭场景无法约束服务端
   账号权限，在应用层杜绝写命令路径才是可控边界；
3. **内容级查看权限 M**——数据库内容（键值/对象/表数据）对家庭 user 暴露
   有隐私风险，清单/概览放开 A；
4. M10-2 工具项保留编号但标注"完整能力并入 M19"，不动 220→239 的计数口径。
