## 过程中发现并修复

1. **mini_sshd 未允许 direct-tcpip**：asyncssh server 默认拒绝转发（connection_requested 需返回 True）——TCP 连上但无响应（curl exit 52）；补 `connection_requested → True`；
2. **asyncssh server 必须提供 server_host_keys**（否则仅 GSS KEX，客户端 KEX 协商失败）——测试 server 用 Ed25519 生成密钥；
3. **p19 test_06 sys.modules fake 泄漏**：真实 asyncssh 模块未预加载导致 real_module=None 恢复跳过 → p20 的 `class _Srv(asyncssh.SSHServer)` 拿到 fake 类报 super 错误——改 importlib.import_module 预加载 + finally 恢复（本阶段发现并回修上阶段测试）；
4. **p13 遗留 httpx 全局污染**：`httpx.Client.__init__ = httpx.AsyncClient.__init__` 永久污染导致后建 TestClient 报 super 错误——删除该"防误改"行；
5. tunnels.py 端点局部变量 `t`（Tunnel）遮蔽 i18n 函数 `t` → 重命名 tun（同 P15 教训）；
6. test_08 后台调度任务并发探测采样导致 up_pct 竞态——放宽为"存在 up 采样点"断言。
