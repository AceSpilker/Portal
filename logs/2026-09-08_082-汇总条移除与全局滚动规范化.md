# 082 · 效率页节假日汇总条移除 + 全局滚动规范化（页面级零滚动条）

## 需求原意

1. 效率页"三个按钮下面"的法定节假日汇总部分不需要了，移除；
2. 全局检查：所有菜单页右侧内容区**不得出现垂直滚动条**，画面内容自适应视口宽高。

## 完成情况

1. **移除节假日汇总条**：SchedulePanel 的 holiday-strip 模板与样式删除（休/班日历角标保留——那是 077 的核心功能）；i18n 的 eff.holidaySummary/restDays/makeUp 键保留（勿删，模板仍引用角标外的汇总已删，仅无引用残留）；
2. **全局滚动规范化**：`styles/index.css` 新增 `.page-anim > *` 规则——所有菜单页右侧内容区**填满视口高度、内部滚动、隐藏垂直滚动条**（scrollbar-width:none + webkit display:none，滚轮/触摸仍可滚）。

## 全页面核查结果（1280×800 实测）

| 页面 | 页面级溢出 | 滚动方式 |
|---|---|---|
| 监控 | 0 | 根容器内滚（隐藏滚动条） |
| 端口 | 0 | 根容器内滚 |
| 工具 | 0 | 根容器内滚 |
| 应用 | 0 | 无需滚动 |
| 日志 | 0 | 视口约束 + 表格内滚（075/076） |
| 设置 | 0 | 菜单/面板各自内滚（080） |
| 效率 | 0 | 日历+侧栏自适应，汇总条已移除 |

## 关键决策

1. **隐藏滚动条而非装饰性细滚动条**：用户明确"不要出现垂直滚动条"；滚轮/触摸滚动不受影响，可视化线索由内容裁切本身提供；
2. 全局规则 `.page-anim > *` 只作用于菜单页根节点，弹窗/抽屉不在其中（弹窗已有 075 的限高与内滚）。

## 遗留

- 隐藏滚动条后长页面的"下方还有内容"无可视化提示，靠滚轮探索（用户明确要求优先）；
- 072~081 遗留不变。
