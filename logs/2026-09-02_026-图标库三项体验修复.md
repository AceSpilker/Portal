# 工作日志 · 2026-09-02 · 026：图标库三项体验修复

---

## 需求（用户原意）

1. 编辑内置图标时预览显示问号，没有把 SVG 显示出来；
2. 分组管理与新增应用的遮罩层显示不对——只盖住右侧内容区，应该盖住整个画面；
3. 图标选择组件里"自定义"和"内置"还分两部分展示，应该统一成一个网格。

## 根因与修复

### 1. 遮罩层只盖内容区（重要）

- **根因**：全局页面动画 `.page-anim` 使用 `animation-fill-mode: both`，动画结束后 `transform: translateY(0)` **永久残留**；元素一旦带 transform，内部的 `position: fixed` 遮罩/弹层就相对该容器定位而非视口——遮罩只盖住内容区；
- **修复**：去掉 `both` 填充（动画结束后样式自然回归无 transform）；应用抽屉与分组弹窗追加 `append-to-body`（挂到 body，彻底脱离页面容器）。

### 2. 内置图标编辑预览问号

- **根因**：编辑弹窗预览只支持图片（preview 路径），内置图标没有图片路径 → 渲染兜底问号；
- **修复**：`iconForm` 增加 `element_name`，预览按优先级渲染：图片 → Element SVG 组件 → 问号兜底。

### 3. IconPicker 统一网格

- 取消「常用 / 自定义 / 内置图标」分区标签，合并为**单一统一网格**（按名称排序，自定义图片与内置 SVG 混排）；常用精选以 ★ 角标 + 高亮边框标识（在设置页图标库管理）；搜索作用于合并后的全列表。
