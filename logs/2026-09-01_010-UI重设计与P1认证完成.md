## 完成情况

### 1. UI 现代化重设计（全站设计系统）

- **设计基调**：深色玻璃拟态（Glassmorphism）+ 极光渐变背景，靛蓝/紫/青三色体系；
- **动效**：极光光斑缓慢漂移（22~30s 循环）、卡片 fade-up 入场、表单项逐项 stagger、路由切换 fade-slide 过渡、按钮悬停上浮 + 光晕、Logo 渐变流光（shimmer）、卡片 hover 抬升；支持 `prefers-reduced-motion` 降级；
- **组件化**：新增 `AuroraBackground.vue`（认证页复用）、`styles/index.css` 设计令牌（色板/玻璃卡片/动效/Element Plus 主色与深色输入框微调）；
- 全站启用 Element Plus 深色主题（`html.dark` + dark css-vars），首屏防白闪。

### 2. 前端接入真实认证流（P1）

- 登录页**自动识别状态**：`/api/health.initialized=false` → 显示"初始化向导"（站点名 + 管理员账号），否则显示登录表单；后端不可达时显示错误横幅；
- axios 拦截器升级：自动附带 JWT、**401 静默续期一次并重试**、续期失败自动登出并跳转登录页；
- 仪表盘换为现代外壳：玻璃侧边导航（当前阶段占位项带 P2/P5/M2 标签）、欢迎横幅、四张占位卡片（应用/监控/AI/Flow）、用户名展示与退出按钮。

### 3. 后端 P1 认证与账户（对齐 feature-spec M01 / api-spec §3.1、§4.1）

- `users` 表（含 `token_version`）；`POST /auth/init` 首次初始化（仅无用户时可用，否则 1005）；
- bcrypt 密码哈希 + JWT（access 30min / refresh 7d）；`GET /auth/me`、`POST /auth/refresh`、`POST /auth/logout`、`PUT /auth/password`（旧密码校验 + 强度校验 + **token_version 递增使所有旧会话失效**）；
- 登录失败限速：同 IP 60 秒内 5 次失败即锁定（1006）。
