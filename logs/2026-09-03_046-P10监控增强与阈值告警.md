## 完成情况

### 10.1 深度采集(M17-10~12)

### 10.2 Docker 维度(M17-13)
- `GET /api/monitor/docker-stats`(A):经 **httpx UDS**(unix socket)调 Docker Engine API `/containers/json` + `/containers/{id}/stats`,换算 CPU%(cpu_delta/system_delta×online_cpus)、内存 used/limit/percent、网络累计;
- `DOCKER_SOCK` 不可达/超时 → 空数组,前端卡片自动隐藏;
- 实测:本机 Docker Desktop 的 Redis/MySQL 容器数据正确显示。

### 10.3 阈值告警引擎(M17-14/15)
- 新模型 `alert_rules`(契约 §3.4:metric/target/op/threshold/duration_min/level/enabled/last_fired_at);
- `services/alerts.py.evaluate_alerts`:**状态机**——越限持续 N 分钟才触发(内存态 violating_since,重启重计);触发经 **P9 dispatch(metric_alert)** 走路由矩阵;冷却 5 分钟(dedup 窗口一致);**恢复发 info 通知**并清状态;指标取值 cpu/mem/disk(挂载点)/disk_io(IOPS 合计,独立 IoRateCalculator)/temp(按传感器名);
- 调度:每 30s(`alerts_evaluate` job);
- 端点:`GET/POST /api/alerts/rules`、`PUT/DELETE /{id}`、`POST /{id}/test`(即时评估不落通知)、`GET /api/alerts/events`(与站内通知同源 source=metric,level/range 过滤);
- 前端:设置 → 通知 改为 **el-tabs 三页**:通知路由(P9)/ 阈值告警(规则 CRUD + 启停 + 测试 + 事件历史)/ 证书监控。

### 10.4 可用性分析(M07-3/4)
- `GET /api/probe/availability?range=24h|7d|30d`(A):窗口起点状态由 app_status.since 推断(unknown 不计损),down 段累计 → 各应用 uptime_pct + 最近 probe_events 时间线;
- 前端监控页「应用可用性」卡:24h/7d/30d 切换、可用率分级着色、最近事件列表。

### 10.5 域名证书监控(M07-6)
- 设置键 `monitor.cert_hosts`(白名单校验 ≤20 条);调度每 6h `certs_check_job`,TLS 握手取 notAfter(**CERT_NONE 不校验信任链**——证书监控只关心有效期;binary_form + cryptography 解析,统一 naive UTC);
- 分级:≤1 天 error / ≤7 天 warn / ≤30 天 info,dedup 按天;端点 `GET /api/monitor/certs`(A,即时)+ `PUT /api/monitor/certs/hosts`(M);
- 前端:通知面板「证书监控」tab(hosts 编辑回填 + 状态列表)、监控页证书卡(未配置自动隐藏)。

## 过程中发现并修复

1. **证书检查 CERTIFICATE_VERIFY_FAILED**:`create_default_context` 校验信任链在无系统 CA 的环境必败——改为 `CERT_NONE` + DER 证书 + cryptography 解析(监控有效期本就不需要验链);
2. `not_valid_after_utc` 为 aware datetime 与 naive utcnow 相减报错 → 统一 naive;
3. `CertHostsIn` 缺单条长度校验(300 字符域名返回 200)→ 补 field_validator;
4. i18n 重复 monitor 段(esbuild duplicate-key 告警)→ 合并。

## 关键决策

1. **告警事件不建新表**:与站内通知同源(notifications.source=metric),`/api/alerts/events` 只是筛选视图——避免双写,与 api-spec「事件历史」语义一致;
2. **触发冷却 5 分钟** = P9 去重窗口,机制上双保险(dedup_key + last_fired_at);
3. **恢复通知**:M17-14 未明确要求,但告警闭环必备(否则不知道何时解除),level=info 走同一事件;
4. **docker-stats 降级**:NAS 未挂载 sock 时静默空数组(与 P24 豁免面一致的"尽力而为"采集原则);
5. **P10 看板 🔄(5/5)**:外部渠道送达待 P9 真机验收同口径;站内链路已实测 < 1 采样周期。
