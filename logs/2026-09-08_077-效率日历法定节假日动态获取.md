# 077 · 效率日历法定节假日动态获取（休几天/调休哪天）

## 需求原意

用户希望效率页日历的**国家法定节假日**动态获取（当前只有农历节日标签，法定休班安排拿不到），并能看到**每个节假日休多少天、调休（替休）在哪天**。

## 方案与完成情况

法定休班是国务院逐年公告的行政安排，无法从农历推算，必须外部数据。采用 **NateScarlet/holiday-cn** 开源数据集（gov.cn 公告的结构化镜像，字段 name/date/isOffDay），四源并发竞速抓取。

| 组件 | 说明 |
|---|---|
| `services/holidays.py`（新） | 多源并发竞速（jsdelivr cdn/fastly/gcore + raw.githubusercontent，4 源同时发谁先成功用谁，总预算 10s）；IPv4 强制（本机 IPv6 路由黑洞致 httpx ConnectTimeout，curl 因 Happy Eyeballs 掩盖）；两级缓存（内存 1h + Setting 表 `calendar.holidays_<year>` 持久化，离线可读）；`summarize` 按节日名聚合休息区间/天数/调休日（纯函数） |
| `GET /api/calendar/holidays?year=` | 登录用户可用；返回 days + summary；数据不可得时 404（前端静默降级） |
| **内置兜底** | 外源全挂时使用内置 2025/2026 国务院公告数据（`_BUILTIN_RANGES`，来源标注 builtin），保证离线/网络波动下功能可用 |
| `SchedulePanel.vue` | 日历格加 **休（红）/班（蓝）角标**；日历上方新增「法定节假日」汇总条：每个节日一行（名称 + 休息起止 + 休 N 天 + 调休上班日期） |
| i18n | eff.holidaySummary / restDays / makeUp（zh/en） |
| 测试 | `tests/test_holidays.py` 3 例：聚合区间合并、端点读 DB 缓存（monkeypatch 证明零外呼）、未登录 401 |

**数据获取策略的教训（实测）**：① 串行 4 源 × 8s 超时会拖垮前端 15s 请求预算 → 并发竞速；② 本机 httpx 直连 jsdelivr 全源 ConnectTimeout 而 curl 可用——IPv6 路由黑洞 + Happy Eyeballs 差异，强制 `local_address="0.0.0.0"` 解决；③ 外源网络时通时断（实测 1 小时内从可用变不可达）→ 内置兜底保证确定性；④ 后端外呼失败需捕获自身超时（asyncio.wait_for 抛 TimeoutError），否则 500 连累前端。

## 测试结果

- 后端：test_holidays 3/3；全量 **232 passed / 2 skipped**（229+3）；ruff ✅；
- 前端：vitest 57/57、build、eslint ✅；
- 本地浏览器实测：日历 9/20 显示蓝色"班"、9/25-27 显示红色"休"（2026 国庆调休真实安排）；汇总条完整显示 2026 全年 7 个节假日的休天数与调休日（数据为内置兜底来源，因本机 jsdelivr 当时不通——兜底机制按设计工作）。

## 遗留

- 数据集覆盖 2004 年至今；用户界面年份超范围时静默无角标；
- 内置兜底数据为 2025/2026 两年，2027 年公告发布后需更新（外源可用时会自动覆盖内置）；
- 更新检测（P17.5）已有 Gitee 通道，节假日亦可在 NAS 上优先尝试 timor.tech 等备用源（本机被 Cloudflare 拦截未采用）。
