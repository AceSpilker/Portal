## 需求（用户原意）

在项目根目录创建并配置好 .gitignore 文件，然后把项目上传到 Gitee 仓库 https://gitee.com/acespilker/portal.git。

## 完成情况

1. **创建 `.gitignore`**（项目根目录），覆盖六类规则：
   - Python（backend）：`__pycache__/`、`.venv/`、`.pytest_cache/`、`.coverage`、`.ruff_cache/` 等；
   - Node/前端（frontend）：`node_modules/`、`dist/`、`.vite/`、各类调试日志；
   - **运行时数据与密钥（绝不入库）**：`data/`、`*.db`、`keys/`、`*.pem`、`*.key`；
   - 环境变量：`.env` / `.env.*`（保留 `.env.example`）；
   - IDE 与操作系统：`.idea/`、`.vscode/`、`.DS_Store`、`Thumbs.db` 等；
   - 临时/备份文件。
2. **初始化仓库**：`git init -b main`（分支 main）；关联远程 `origin → https://gitee.com/acespilker/portal.git`；
3. **本地提交完成**：commit `2adbdaa`，共 16 个文件（docs/ 8 个 + logs/ 7 个 + .gitignore），提交身份使用全局配置 `linzhongyang <linzhongyang@dxwsoft.net>`。

## 关键决策

1. **数据卷与密钥目录整体排除**（`data/`、`keys/`、`*.db`）：SQLite 主库、SSH 私钥、上传文件只存在于部署环境，进仓库会有泄露风险；
2. 分支采用 `main`；远程用 HTTPS（首次推送需认证）。

## 遗留 / 下一步（推送被认证阻塞）

- 诊断结果：Gitee 网络连通正常（HTTP 200），但仓库页面返回 **403（私有仓库）**，且本机**未配置 credential.helper**，推送需要 Gitee 账号凭证；
- 待用户择一完成后即可推送（`git push -u origin main`）：
  1. **私人令牌（推荐）**：Gitee → 设置 → 安全设置 → 私人令牌，生成 scopes 含 `projects` 的令牌，把令牌提供给我配置后推送；
  2. **SSH 方式**：把本机公钥（`~/.ssh/id_rsa.pub` / `id_ed25519.pub`）添加到 Gitee，改用 SSH 远程；
  3. **自行推送**：在终端手动执行 `git push -u origin main`，按提示输入 Gitee 用户名与密码（或令牌）。
