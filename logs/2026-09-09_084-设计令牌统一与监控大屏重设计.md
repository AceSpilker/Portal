# 084 · 全站设计令牌统一封装 + 监控大屏模式重设计

## 需求原意

用户两点反馈：
1. 监控页大屏模式太丑——此前只是把页面元素盖在一块纯色深底（`#060b1c`）上，卡片仍是亮色玻璃，
   亮卡片贴深底观感割裂；
2. 全站各页背景色、块状阴影不统一——各视图散落着多套写死的灰色底与阴影值，暗色主题下有的还不跟随。

## 完成情况

### 1. 设计令牌统一封装（styles/index.css）

- **圆角体系**：`--p-radius-lg`（20px 卡片/.glass）/ `--p-radius`（14px 常规面板）/ `--p-radius-sm`（10px 内嵌块）；
- **阴影层级**：`--p-shadow-sm`（浮点小件）/ `--p-shadow`（卡片默认）/ `--p-shadow-hover`（悬停）/ `--p-shadow-pop`（弹层），暗色主题各配深色版；
- **软填充两级**：`--p-soft`（6% 文字色）/ `--p-soft-2`（11%），暗色自动跟随；
- **语义状态色**：`--p-up`（#22c55e）/ `--p-down`（#ef4444），首页/布局/监控三处状态点统一走令牌；
- `.glass` 圆角、`.hover-lift` 悬停阴影改走令牌——全站卡片表面唯一封装点。

### 2. 全站散落样式清理（9 个视图/组件）

硬编码 → 令牌：AI 页会话悬停/气泡/引用块/键值块、Docker 页日志窗/键值块、Flow 运行步骤、
应用管理行卡、设置图标操作钮、首页磁贴悬停阴影与操作钮、FlowCanvas 节点阴影、AppLayout 状态点。
保留语义特例：二维码白底（扫码需要）、危险色悬停底、AI 代码块深底。

### 3. 监控大屏模式重设计（MonitorView）

- **暗色数据墙**：固定全屏，深蓝渐变底 + 主色/青色径向光晕；
- **变量级联暗色化**：在 `.wall-mode` 容器上重定义全套 `--p-*` 与 `--el-*` 变量（写法对齐 html.dark），
  所有 `.glass` 面板与 Element Plus 组件零改动整体变暗——子组件（进程榜/Docker/可用性/证书卡）自动跟随；
- **HUD**：左＝渐变主机名 + 长日期，右＝大号秒级时钟（wallMode 期间每秒 tick）+ 退出按钮；
  隐藏原页头（工具动作不属于数据墙）与入场动画；
- **密度**：图表网格 minmax 340→400px、间距 14→12px、卡片内边距收紧；
- **交互闭环**：进入时尝试全屏（被拒不影响大屏态）；Esc/程序退出全屏经 `fullscreenchange` 联动退出大屏；
  退出按钮/卸载清理定时器；根节点改 `:class` 绑定 + 模板 ref（替代 querySelector）；
- i18n 新增 `monitor.wallExit`（中/英）。

## 测试结果

- 前端关卡：vitest 57/57 ✅、eslint ✅、build（vue-tsc）✅；
- 本地浏览器实测（localhost:5173 + 本地 8000，localadmin）：
  - 常规监控页外观不变 ✅；
  - 大屏进入：暗色墙 + HUD 时钟走秒 + 全屏生效 ✅；
  - 滚动到底：进程 Top 榜/应用可用性/历史曲线全部暗色渲染正常 ✅；
  - 退出大屏按钮：class 移除、恢复正常视图 ✅；
  - 程序退出全屏 → fullscreenchange 联动退出大屏 ✅；
  - 全屏被拒（stub reject）→ 大屏仍生效且铺满视口 ✅（实测截图中偶发的底部/右侧黑带为内嵌浏览器
    全屏仿真的截图伪影：元素 rect 实测 1600×900 @ (0,0)，非全屏路径无黑带可证伪）；
  - 首页抽查：令牌替换后外观无回归 ✅。

## 关键决策

1. 统一手段选「令牌 + 变量级联」而非逐组件改样式：一套 `--p-*/--el-*` 覆盖同时解决亮暗两主题与
   大屏第三态，后续新页面只需用令牌；
2. 阴影分四级而非单一值：浮点/卡片/悬停/弹层的视觉重量本就不同，先分层再统一；
3. 大屏隐藏页头只留 HUD 出口：大屏是"挂机看板"形态，配置类动作回常规页操作。

## 遗留

- Element Plus 表格/分页等在大屏内未逐一目检（本机无 Docker 容器行数据），令牌覆盖理论上成立，
  NAS 实机如有漏网再补；
- `--p-radius-sm` 暂未大规模替换散落的 6/8px 小圆角（数量多收益低，后续渐进）。
