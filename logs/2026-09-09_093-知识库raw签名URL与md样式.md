# 093 · 知识库 raw 预览签名 URL + Markdown 阅读样式

## 需求原意

用户反馈两个问题：
1. HTML 文件预览失败，显示 `{"code":1002,"message":"err.unauthenticated"}`；
2. Markdown 显示效果不对——表格没有边框线，和常规 md 阅读器观感差距大。

## 根因

1. **1002**：html/pdf/图片/视频的预览走 `<iframe>/<img>/<video>` 加载 `/raw` 原文件流，
   浏览器发这类请求**无法携带 Authorization 头** → 被鉴权依赖拒绝。另外本地开了传输加密时
   还会先被 1100（secure session required）拦截。
2. **MD 无表格线**：marked 只负责转 HTML，没有任何配套 CSS——表格/代码块/引用等全部裸排。

## 完成情况

### 1. raw 短期签名 URL（092 增补）

- `raw-url` 端点：签发 `?path=…&exp=…&sig=…`（HMAC-SHA256(secret, `id:path:exp`)，默认 10 分钟）；
- `raw` 端点鉴权双通道：Authorization 头 **或** 有效签名（比对一致且未过期）；
- 传输加密中间件对带 `sig=` 的 knowledge raw 请求豁免（签名即授权票据）；
- 前端打开 html/image/video/audio/pdf/binary 时先换签名 URL 再渲染；
  该 URL 会过期，重开文件自动重签。

### 2. Markdown 阅读样式（.kb-md :deep）

对齐常规 md 阅读器：表格全边框+表头底色+斑马纹、代码块底色边框圆角、行内 code 样式、
blockquote 左侧主色条、h1/h2 下划线层级、列表间距、图片限宽、分隔线、链接主色。

## 测试结果

- 后端：全量 **254 passed / 2 skipped**，ruff ✅；
- 前端：vitest 57/57 ✅、eslint ✅、build ✅；
- 本地浏览器实测：md 表格全边框+表头底色+斑马纹渲染正常 ✅；html 签名 URL iframe
  预览正常（标题+表格完整呈现，此前 1002/1100 双拦）✅。

## 关键决策

1. 签名 URL 而非 cookie/降级匿名：HMAC+过期时间最小改动、可 revoke（改 secret 全失效）、
   不引入会话语义；
2. 传输加密对带 sig 的 raw 豁免：签名本身即授权，信封加密对无头场景无法实施；
3. md 样式走 :deep 作用域 CSS 而非引第三方 md CSS 库：零依赖、跟随主题变量。

## 遗留

- html 文件内的相对路径子资源（图片等）经 srcdoc/签名主文档后仍各自鉴权，未跟随签名；
- 签名 URL 10 分钟内可被转发访问（自托管家庭场景风险可接受）。
