# 105 · 首页应用磁贴探活绿点改图标右上角角标

## 需求原意

用户反馈：首页每个应用磁贴上的探活小绿点"显示位置不对，现在显示在图标内，
应该是右上角的位置"。

## 原因

`.status-dot` 挂在 `.tile-icon`（30px 图标容器）内，`top:8px; right:8px`
的定位点落在图标内部——视觉上像画在图标上，而非角标。

## 完成情况（纯前端样式，`HomeView.vue`）

- 定位改为 `top:-3px; right:-3px`：绿点**骑在图标右上角**（头像在线角标
  的通用样式）；
- 点径 8px → 9px，并加 `box-shadow: 0 0 0 2px var(--p-card)` 描环与磁贴
  底色融边，避免与图标图形糊在一起；
- up（绿）/down（红+脉冲）/unknown（灰）三态样式不变。

## 测试结果

- 前端：vitest **57/57** ✅、eslint ✅、vue-tsc + build ✅；
- **浏览器实测**（本地临时实例，新建应用 Jellyfin 并配置 HTTP 探活指向
  本地 health 接口）：首页磁贴绿点位于图标右上角角标位、探活成功显示
  绿色带描环 ✅；
- 纯样式改动，无接口/契约变更。

## 遗留

- 如用户本意是"磁贴卡片右上角"（而非图标角标），仅需把定位锚点从
  `.tile-icon` 改挂 `.tile`（top/right 各 10px 上下），一行改动。
